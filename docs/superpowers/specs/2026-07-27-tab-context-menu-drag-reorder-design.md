# 标签右键菜单与拖动排序设计

## 背景与目标

SideTab Lite 当前支持标签搜索、切换、关闭以及由 Chrome 事件驱动的增量同步。本次变更在不引入额外排序存储、不增加高频 Chrome API 调用的前提下，补充以下能力：

- 右键标签页时显示轻量菜单，可复制标签页、固定标签或取消固定。
- 直接拖动标签行调整上下位置，并同步 Chrome 当前窗口的真实标签顺序。
- 拖动跨越固定标签与普通标签区域时，自动切换标签固定状态。
- 快捷网站开启时，在快捷入口与标签列表之间显示 1px 浅灰色通栏分割线。

性能仍为首要约束。拖动过程中只更新必要的视觉状态，松手后才提交 Chrome 标签操作。

## 范围

### 包含

- 当前窗口标签行的自定义右键菜单。
- 调用 `chrome.tabs.duplicate` 复制标签页。
- 调用 `chrome.tabs.update` 固定或取消固定标签。
- 调用 `chrome.tabs.move` 调整当前窗口标签顺序。
- 同组与跨组拖动、首尾插入、插入位置提示。
- 搜索过滤期间禁用拖动排序。
- 快捷入口与标签列表之间的条件分割线。
- 对应的单元测试、DOM 测试、视觉验收和发布检查更新。

### 不包含

- 多选标签或批量拖动。
- 跨窗口拖动。
- 侧边栏独立排序或排序结果持久化。
- 触屏专用拖动手势。
- 键盘调整标签顺序。
- 调用系统剪贴板或复制标签网址文本。
- 使用 Chrome 原生扩展 `contextMenus` API。

## 右键菜单交互

用户在标签行上点击鼠标右键时，阻止浏览器默认菜单并在指针附近显示侧边栏内的自定义菜单。菜单包含两个命令：

1. `复制标签页`：调用 `chrome.tabs.duplicate(tabId)`。
2. 普通标签显示 `固定标签`；固定标签显示 `取消固定`，调用 `chrome.tabs.update(tabId, { pinned })`。

菜单必须限制在侧边栏可视范围内。靠近右边缘或底部打开时，应向左或向上调整位置，不能产生横向滚动条，也不能遮挡到视口外。

菜单打开后，第一个可用菜单项获得焦点。支持方向键在菜单项之间移动、`Enter` 或空格执行、`Esc` 关闭。标签行获得键盘焦点时，`Shift+F10` 可以在该行附近打开相同菜单。

发生以下任一情况时关闭菜单：命令执行、点击菜单外部、按 `Esc`、标签列表滚动、侧边栏尺寸变化、目标标签被关闭或侧边栏销毁。菜单使用 `role="menu"` 和 `role="menuitem"`，动态固定命令的文本必须与当前标签状态一致。

复制标签页、固定或取消固定失败时，菜单关闭，并通过现有底部状态区显示明确错误。标签已经不存在时不保留失效菜单。

该功能只使用现有 `tabs` 权限，不增加 `clipboardWrite` 或 `contextMenus` 权限。

## 拖动排序交互

标签行整体可拖动。用户从关闭按钮开始拖动时不进入排序，避免关闭操作与拖动冲突。拖动中的源行降低不透明度，但保持原有 30px 行高，不能导致列表重排抖动。

指针位于目标行上半部分时表示插入目标之前，位于下半部分时表示插入目标之后。目标位置显示稳定的水平插入线。插入线通过行状态或伪元素实现，不插入会改变列表高度的占位节点。

拖动到目标标签所属区域会决定源标签的最终固定状态：

- 放到固定标签之前或之后，源标签最终为固定状态。
- 放到普通标签之前或之后，源标签最终为普通状态。

因此在固定区与普通区交界处，放到最后一个固定标签之后仍表示固定；放到第一个普通标签之前则表示普通。该规则避免边界位置产生双重解释。

同组拖动只调用一次 `chrome.tabs.move`。跨组拖动先调用 `chrome.tabs.update(tabId, { pinned: targetPinned })`，成功后再调用一次 `chrome.tabs.move`，移动到从最终完整顺序计算出的绝对索引。任一步失败都停止后续操作并显示错误。

拖动过程中不得调用 `chrome.tabs.update` 或 `chrome.tabs.move`。松手后才提交操作，并且同一时间只允许一个排序操作。排序期间拒绝新的拖动开始，完成或失败后恢复。

侧边栏不进行乐观 DOM 重排，也不保存自定义顺序。Chrome 的 `onUpdated` 和 `onMoved` 事件继续作为固定状态与顺序的最终事实来源，现有标签存储和增量渲染流程负责同步结果。

搜索框存在非空查询时，所有标签行禁用拖动，并通过标题提示“清空搜索后可排序”。清空搜索且过滤结果恢复后重新启用拖动。这样不会把可见结果错误地映射到被隐藏标签之间。

拖动取消、离开有效目标、源标签消失或侧边栏销毁时，只清理拖动状态，不调用 Chrome API。

## 快捷入口分割线

快捷网站功能开启且快捷入口区域实际显示时，在该区域底部显示 1px 浅灰色通栏分割线。深色主题使用可辨识但克制的中性边框色。

快捷网站关闭时，快捷入口区域保持 `hidden`，分割线随之隐藏且不占任何高度。分割线使用现有快捷入口区域的 CSS 边界或伪元素实现，不新增纯装饰 DOM 节点。

## 模块边界

### `tab-context-menu`

- 创建并维护唯一的菜单 DOM。
- 处理右键、键盘打开、焦点移动、视口内定位和关闭生命周期。
- 将 `duplicate`、`toggle-pinned` 命令连同标签 ID 分发给侧边栏协调层。
- 不直接依赖 Chrome API。

### `tab-drag-controller`

- 绑定标签列表的委托式拖放事件。
- 识别源标签、目标标签、前后插入位置和目标固定分组。
- 管理源行与插入线的临时视觉状态。
- 在有效松手时输出一次排序意图，在取消时只清理状态。
- 不直接依赖 Chrome API，也不修改标签存储。

### `tab-reorder-model`

- 以当前完整标签快照、源标签、目标标签和前后位置为输入。
- 输出最终固定状态和绝对目标索引。
- 处理向上、向下、首位、末位和跨组移动时的索引偏移。
- 作为纯函数独立测试，避免把索引计算散落在 DOM 事件代码中。

### `tab-actions`

- 扩展现有动作封装，增加复制、固定状态切换和移动。
- 跨组排序严格按“更新固定状态，再移动”的顺序执行。
- 将 Chrome API 异常转换为稳定的中文错误信息。

### 侧边栏协调层

- 从标签存储读取右键菜单和拖动所需的当前标签模型。
- 在搜索状态变化时启用或禁用拖动。
- 将菜单命令和排序意图交给 `tab-actions`。
- 复用现有操作状态槽显示成功清理或失败信息。
- 在标签删除、列表滚动和页面销毁时关闭菜单或取消拖动。

## 数据流

### 右键命令

1. 列表收到 `contextmenu` 或键盘菜单事件。
2. 协调层根据 `data-tab-id` 从标签存储取得当前模型。
3. 菜单根据标签固定状态渲染命令并定位。
4. 用户执行命令后，菜单立即关闭并调用对应标签动作。
5. Chrome 事件返回后，现有存储和渲染器同步标签状态或新增的复制标签。
6. 操作失败时，底部状态区显示错误。

### 拖动排序

1. `dragstart` 记录源标签 ID；搜索非空、操作进行中或起点为关闭按钮时取消。
2. `dragover` 只计算目标、前后位置与目标分组，并更新插入线。
3. `drop` 使用当前完整标签快照生成一次排序计划。
4. 同组执行一次移动；跨组顺序执行固定状态更新和移动。
5. Chrome 的 `onUpdated`、`onMoved` 事件更新标签存储和 DOM。
6. `dragend`、失败或销毁统一清理所有临时样式与状态。

## 性能约束

- 标签列表继续使用事件委托，不为每行增加独立的全局监听器。
- 右键菜单 DOM 全局只保留一个实例，按需更新文本和位置。
- `dragover` 不查询 Chrome API、不重建列表、不写入存储。
- 插入提示只修改前一个目标和当前目标的 class 或 data 属性。
- 每次有效同组拖动最多一次 Chrome API 调用；跨组最多两次。
- 无效拖动、原地放置和取消拖动不调用 Chrome API。
- 标签最终状态只保存在现有内存模型中，不增加排序缓存或 Chrome Storage 写入。

## 错误处理

- 复制失败：显示“无法复制该标签页”。
- 固定状态切换失败：显示“无法更新标签固定状态”。
- 移动失败：显示“无法移动该标签页”。
- 目标或源标签在操作前消失：取消操作或按 Chrome API 失败处理，不保留菜单和拖动状态。
- 跨组操作中固定状态更新成功但移动失败：不尝试手工回滚固定状态，以 Chrome 当前真实状态为准，并等待事件同步后提示移动失败。
- 所有异步结果沿用操作代次控制，较早操作不得覆盖较新操作的状态信息。

## 样式与响应式要求

- 菜单使用紧凑中性样式，圆角不超过 6px，文字不得截断。
- 180px 侧边栏宽度下菜单完整显示在视口内，不产生横向滚动。
- 菜单层级高于标签列表和底部工具栏，但不改变它们的布局尺寸。
- 插入线在浅色和深色主题下均清晰，且不改变 30px 标签行高度。
- 拖动源行、当前标签、悬停标签和固定状态仍可区分。
- 快捷入口分割线不改变底部工具栏固定位置。

## 测试与验收

### 单元测试

- 排序计划覆盖同组向上、向下、移动到首尾和原地放置。
- 排序计划覆盖普通转固定、固定转普通及分组交界位置。
- `tab-actions` 验证复制、固定切换、同组移动和跨组调用顺序。
- Chrome API 任一步失败时返回对应中文错误，跨组第一步失败时不得调用移动。

### DOM 与集成测试

- 右键菜单文本、动态固定命令、焦点、方向键、`Esc` 和外部点击关闭。
- 菜单在右下角打开时仍位于视口内。
- `复制标签页`、`固定标签`、`取消固定` 分发正确标签 ID。
- 搜索非空时拖动被阻止，清空后恢复。
- 关闭按钮不触发拖动；有效放置只分发一次排序意图。
- 拖动取消、目标消失和销毁均清理临时状态。
- 快捷入口开启时显示分割线，关闭时不占空间。

### 性能与视觉验收

- 100 和 500 个标签场景中，`dragover` 不调用 Chrome API且不重建全部标签节点。
- 同组放置最多一次 API 调用，跨组最多两次。
- 在 180、240、300、360px 宽度及浅色、深色主题下检查菜单、插入线、分割线、长标题和底部工具栏。
- 标签行持续保持 30px，页面无横向滚动条。

### 发布验收

- Manifest 权限仍精确为 `sidePanel`、`tabs`、`storage`。
- 不新增 `clipboardWrite`、`contextMenus`、host permission 或 content script。
- `npm run package`、发布清单审计和确定性 ZIP 测试通过。

## 验收标准

- 右键任一有效标签可复制标签页，并可根据当前状态固定或取消固定。
- 菜单支持鼠标和基础键盘操作，始终位于侧边栏可视范围内。
- 标签可拖动同步 Chrome 真实顺序，跨组时正确切换固定状态。
- 搜索期间不能拖动，清空搜索后恢复。
- 拖动期间无 Chrome API 调用，松手后调用次数符合性能约束。
- 快捷入口开启时显示 1px 浅灰色通栏分割线，关闭时不占空间。
- 180px 宽度下没有菜单、标题、关闭按钮或底部工具栏裁切和横向溢出。
- 发布权限没有扩大，完整测试和打包检查通过。
