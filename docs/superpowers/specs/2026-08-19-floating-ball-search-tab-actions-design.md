# 网页悬浮球搜索与标签快捷操作设计

日期：2026-08-19

## 目标

在普通网页右下角提供一个默认关闭、可拖拽并记忆位置的 SideTab Lite 悬浮球。用户可以在不离开当前网页的情况下快速搜索书签与历史记录，并通过悬浮球右键菜单操作活动标签或执行当前窗口的一键分组。

本功能复用侧边栏现有搜索与智能分组语义，不部署独立后台服务，不读取网页正文，不发送外部网络请求。

## 已确认需求

1. 悬浮球只出现在 `http://` 与 `https://` 普通网页，不出现在 `chrome://`、扩展页、新标签页等受限页面。
2. 侧边栏设置新增“网页悬浮球”开关，默认关闭；开关变化立即作用于已经打开的普通网页，无需刷新。
3. 悬浮球可拖拽，全站共用同一位置，并在窗口尺寸变化后保持在可见区域。
4. 左键点击悬浮球后，搜索胶囊从球体向左展开，结果列表显示在输入框上方，输入框立即获得焦点。
5. 搜索复用侧边栏的书签与历史记录能力；空关键词显示最近访问记录，非空关键词优先展示最多 5 条书签，再用历史记录补足到最多 20 条。
6. 右键菜单包含复制标签页、固定或取消固定、关闭标签页、打开侧边栏和一键分组。
7. 除一键分组外，右键菜单操作都针对触发菜单的活动标签；一键分组沿用侧边栏语义，处理当前窗口全部待分组标签。
8. 一键分组必须复用现有同名分组：网站分组或“其他”分组已经存在时直接加入；存在多个同名分组时合并到稳定选定的目标分组，不创建新同名分组。
9. 页面进入全屏时临时隐藏悬浮球，退出全屏后按原位置恢复。
10. 图标采用单色“侧边栏 + 标签列表”图形，不叠加放大镜。

## 架构

采用“内容脚本 + Shadow DOM + Manifest V3 Service Worker”架构：

```text
侧边栏设置
    │ 写入 chrome.storage.local
    ▼
Service Worker ── 注入/消息 ──► 普通网页内容脚本
    │                              │
    │ Chrome APIs                  └─ Shadow DOM 悬浮球、搜索框、菜单
    ▼
书签、历史记录、标签页、标签组、侧边栏
```

### 内容脚本

内容脚本在隔离世界中运行，仅负责：

- 读取悬浮球配置并监听配置变化。
- 创建一个固定定位的宿主节点和关闭模式 Shadow DOM。
- 渲染悬浮球、搜索框、结果列表、右键菜单、忙碌状态和错误提示。
- 处理拖拽、焦点、键盘导航、点击外部关闭、视口变化与全屏变化。
- 通过类型化扩展消息请求后台搜索或执行命令。

内容脚本不直接读取网页正文，不将页面 DOM、URL 或标题发送到外部，也不加载远程脚本、字体或样式。

### Service Worker

Service Worker 是扩展内置后台，不需要单独部署。它负责：

- 合并书签和历史记录搜索结果。
- 使用消息发送方 `sender.tab` 确定操作目标。
- 执行复制、固定、取消固定和关闭标签页。
- 在用户点击菜单后调用 `chrome.sidePanel.open()`。
- 调用抽取后的共享智能分组用例，保持与侧边栏一致的同名分组复用与合并行为。
- 在开启功能时向已打开且符合条件的页面补充注入内容脚本。

Service Worker 可以随时休眠，所有持久状态均保存在 `chrome.storage.local`，不依赖后台内存存活。

### 共享用例

侧边栏现有搜索流程和一键分组流程需要从页面控制器中抽取为可复用用例：

- 搜索用例接收关键词，调用书签、历史记录适配器并返回统一结果模型。
- 智能分组用例接收当前窗口标签与原生标签组快照，生成并执行稳定的分组操作。
- 侧边栏与 Service Worker 只负责收集 Chrome 数据、展示状态和处理错误，不各自复制业务规则。

共享用例保持现有用户语义，特别是网站分组、“其他”分组及多个同名分组的复用与合并规则。

## 权限与兼容性

清单新增：

- `host_permissions`: `http://*/*`、`https://*/*`。
- `content_scripts`: 对上述地址在 `document_idle` 注入悬浮球入口。
- `permissions`: 新增 `scripting`，用于给扩展安装或更新前已经打开的合规网页补充注入。

用户已选择安装时静态申请所有普通网站权限。Chrome 会显示相应站点访问权限提示。`chrome.scripting` 同时需要 `scripting` 与目标站点权限，参见 [Chrome scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting)。

项目的 `minimum_chrome_version` 从 114 提升到 116，因为 `chrome.sidePanel.open()` 从 Chrome 116 开始提供，且只能响应用户操作调用，参见 [Chrome Side Panel API](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)。右键菜单点击产生的用户手势必须直接沿消息路径触发该调用，不得放入延迟任务。

### 已打开页面即时生效

声明式内容脚本负责后续新导航。为覆盖安装、更新或重新加载扩展前已经打开的网页，开启设置时 Service Worker 查询当前所有普通网页标签并通过 `chrome.scripting.executeScript()` 注入入口脚本。

入口脚本使用扩展版本无关的全局哨兵保证幂等：

- 已存在当前运行实例时不重复挂载。
- 旧扩展上下文失效或消息端口断开时允许新实例替换宿主节点。
- 关闭设置时，所有仍有效的内容脚本收到配置变化并立即卸载界面和监听器。
- 无权访问或已经关闭的标签跳过，不使整个批次失败。

## 设置与状态

新增独立的悬浮球设置模型，不放入快捷键设置对象：

```text
FloatingBallSettings
  enabled: boolean = false
  position:
    xRatio: number
    yRatio: number
```

- `enabled` 默认 `false`。
- 初始位置位于视口右下角，距边缘 20px。
- 拖拽结束后才持久化位置，移动过程中不连续写存储。
- 使用视口比例坐标支持不同窗口尺寸；恢复时将球体限制在至少 12px 的安全边距内。
- 设置对所有网站共用，不按域名分别保存。
- 全屏隐藏属于瞬时界面状态，不修改持久设置。

侧边栏设置对话框分别加载和保存快捷键设置与悬浮球设置，任一配置写入不能覆盖另一配置。内容脚本通过 `chrome.storage.onChanged` 响应已有实例的开关和位置变化；开启时的补充注入由设置保存后发送给 Service Worker 的显式命令完成。

## 交互设计

### 悬浮球

- 默认尺寸 44px，使用高对比度单色图标和轻量阴影。
- 正常点击与拖拽通过 5px 移动阈值区分；拖拽结束不触发搜索。
- 按钮具有可访问名称和清晰的键盘焦点样式。
- 页面全屏时隐藏；退出全屏后恢复。
- 视口变化时重新计算安全位置，搜索面板和菜单根据剩余空间自动换向。

### 搜索

- 左键点击后，胶囊从球体向左展开，输入框立即聚焦。
- 空关键词立即展示最近访问记录；输入采用 100ms 防抖。
- 每个请求带单调递增序号，旧请求结果不能覆盖新关键词结果。
- 结果列表位于输入框上方，展示 favicon、标题、URL 与“书签”或“历史”来源。
- 支持上下方向键切换、Enter 打开、Escape 收起；点击外部关闭。
- 选择结果后创建活动标签页并收起搜索界面。
- 搜索失败时在结果区展示简短错误状态，不影响悬浮球与快捷菜单。

### 右键菜单

只在悬浮球上阻止网页原生右键菜单。菜单根据空间显示在悬浮球上方或侧方，包含：

1. 复制标签页。
2. 固定或取消固定，文案根据最新标签状态变化。
3. 关闭标签页。
4. 打开侧边栏。
5. 一键分组。

命令执行期间禁用重复点击。成功后关闭菜单；失败时保留菜单并显示简短错误提示。一键分组继续使用既有忙碌门禁、部分失败状态与一次重新同步机制。关闭活动标签成功后，内容脚本随页面销毁自然结束。

## 消息协议与安全边界

消息使用可判别联合类型，至少包含：

- `floating-ball/search`
- `floating-ball/duplicate-tab`
- `floating-ball/toggle-pin`
- `floating-ball/close-tab`
- `floating-ball/open-side-panel`
- `floating-ball/smart-group-window`
- `floating-ball/ensure-injected`

后台必须验证消息类型、关键词类型和长度，并验证发送方是扩展页面或具有合法 `http/https` URL 的标签。页面命令不得携带可用于选择其他标签的 Tab ID；后台始终使用 `sender.tab.id` 与 `sender.tab.windowId`。一键分组只能以该窗口为范围。

搜索关键词设置合理长度上限；错误响应只返回稳定错误码与可展示消息，不向页面泄露异常堆栈。所有监听器在界面卸载时移除。

## 错误与边界

- 受限页面、无权限页面和已关闭标签直接跳过注入。
- 单个页面注入失败不阻止其他页面即时启用。
- 搜索请求失败或 Service Worker 被重新唤醒时允许重试，不保留悬空忙碌状态。
- 标签在命令执行前关闭、移动到其他窗口或失效时返回受控错误。
- 页面进入打印预览、卸载或全屏时清理临时界面和未决请求展示。
- 网页样式不能进入 Shadow DOM；悬浮球样式不得依赖网页 CSS 变量。
- 搜索和菜单不能同时展开，打开一个必须关闭另一个。

## 测试与验收

### 自动化测试

1. 设置默认关闭，保存后不覆盖现有快捷键设置，开关变化可挂载与卸载已有内容脚本。
2. 开启时只给 `http/https` 标签补充注入，单标签失败不影响批次，重复注入不重复挂载。
3. 拖拽阈值、全局位置持久化、视口比例换算、安全边距和全屏隐藏/恢复。
4. 左键展开后自动聚焦；空关键词显示最近记录；Escape、点击外部和搜索结果选择行为正确。
5. 搜索保持书签最多 5 条、总数最多 20 条、100ms 防抖和旧响应丢弃。
6. 后台从 `sender.tab` 取得目标，页面提供伪造 Tab ID 时不能操作其他标签。
7. 复制、固定/取消固定、关闭与打开侧边栏成功和失败路径。
8. 一键分组处理当前窗口，并覆盖网站分组、“其他”分组及多个同名分组复用合并。
9. Shadow DOM 隔离、搜索和菜单互斥、窄屏或边缘位置自动换向。
10. 清单权限、最低 Chrome 版本、构建入口和发布文件完整性。

### 实机验收

1. 在 Chrome 116 及以上重新加载扩展，确认安装时站点权限提示与设计一致。
2. 保持多个普通网页已打开，在设置中启用和关闭悬浮球，确认所有页面无需刷新即时显示或移除。
3. 验证拖拽位置跨站点、刷新和窗口尺寸变化后恢复。
4. 验证空搜索、关键词搜索、键盘操作和结果打开。
5. 验证五项右键命令，尤其是从网页用户手势直接打开侧边栏。
6. 准备网站分组、“其他”分组和多个同名分组，确认一键分组复用并合并，不创建重复组。
7. 进入和退出视频全屏，确认悬浮球隐藏并恢复。

完成实现后运行：`npm run typecheck`、`npm test -- --run`、`npm run build`、`node scripts/check-dist.mjs`。如执行正式打包，还必须先扫描公司、个人、凭据和内部地址等敏感信息，再更新版本号与 `update.log`。

## 非目标

- 不搜索当前打开标签页或互联网搜索引擎。
- 不为不同网站保存不同悬浮球位置。
- 不在受限 Chrome 页面显示悬浮球。
- 不部署远程后台、遥测或同步服务。
- 不读取、索引或上传网页正文。
- 不在本次新增可自定义菜单项、尺寸、透明度或主题。
