# 设置齿轮图标尺寸优化设计

## 背景

当前侧边栏底部的设置齿轮使用继承的正文尺寸渲染，视觉尺寸偏小，不易识别。需要在不改变底部工具栏布局和点击可用性的前提下放大图标。

## 目标

- 设置齿轮图标视觉字号固定为 `18px`。
- 保留现有 `32px × 32px` 的按钮点击区域。
- 保持无边框、无背景的齿轮样式，以及搜索框和齿轮的底部固定布局。
- 将发布版本从 `0.6.0` 升级为 `0.6.1`。

## 方案

仅调整 `#shortcut-settings` 的 CSS `font-size` 为 `18px`。不引入 SVG、图片资源或缩放变换，避免增加资源和渲染复杂度。现有按钮尺寸由 `.icon-button` 继续控制，图标字号与点击区域解耦。

## 测试

- 在侧边栏 CSS 测试中增加 18px 齿轮字号断言。
- 运行完整 TypeScript 类型检查、Vitest 测试、构建和发布包检查。
- 确认生成包的版本为 `0.6.1`，且 ZIP 内容不包含开发目录。

## 非目标

- 不调整搜索框尺寸、间距、位置或圆角。
- 不改变设置按钮的交互、无障碍名称和焦点样式。
- 不新增设置项，不改变标签标题字号配置。
