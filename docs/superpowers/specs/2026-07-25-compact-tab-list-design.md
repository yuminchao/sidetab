# 紧凑标签列表与底部工具栏设计

## 变更目标

在不改变标签管理功能的前提下，提高侧边栏的信息密度，并让界面在更窄的内容宽度下保持可用。视觉密度参考用户提供的 Edge 左侧标签栏截图。

## 标签列表

- 标签行固定为约 30px 高，一屏尽量显示更多标签页。
- 每行只显示固定状态图标（仅固定标签）、16px 网站图标、单行标题和关闭按钮。
- 不显示域名、URL 或第二行辅助文字；域名和 URL 仍保留在内存模型中，用于搜索。
- 标签行之间不显示分割线，通过悬停、当前标签背景和留白区分相邻标签。
- 标题始终单行省略，不允许撑宽侧边栏。
- 关闭按钮保留固定宽度，默认弱化；在行悬停、键盘聚焦或当前标签状态下清晰显示。
- 当前标签使用克制的背景色和左侧强调线，不增加行高；标签之间没有横向分割线。
- 固定标签始终排在普通标签之前；两个区域内部仍按 Chrome 标签索引排序。
- 固定标签在整行最左侧显示紧凑的本地图钉图标，普通标签不保留图钉占位。
- 图钉只作为图形显示，不再显示“固定”中文；固定状态同时写入标签按钮的可访问名称。
- 图钉使用随扩展打包的本地矢量资源或等价的本地图标路径，不增加图标框架和网络请求。

## 网站图标

- 标签页图标不由扩展生成。
- 优先使用 Chrome `tabs.Tab.favIconUrl` 提供的网站图标。
- 不由扩展主动拼接网站根目录的 `/favicon.ico`，因为该路径并非所有网站都使用。
- 图标缺失或加载失败时显示标题首字符。
- 扩展不调用 `fetch`、XHR 或第三方 favicon 服务；浏览器可能为 Chrome 提供的 HTTPS favicon URL 使用缓存或发起图片请求。
- Manifest CSP 的图片策略允许本地资源、`data:` 图片和 HTTPS favicon；脚本、连接、frame 和远程样式仍保持严格禁止。

## 底部工具栏

- 搜索框和快捷网站设置按钮从顶部移到底部。
- 底部工具栏固定在侧边栏底部，不随标签列表滚动。
- 标签列表占据剩余高度并独立滚动。
- 搜索框使用剩余宽度，设置按钮保持固定 30 至 32px 尺寸。
- 状态或错误信息显示在底部工具栏上方；没有消息时不占高度。
- 快捷网站区启用时仍显示在标签列表上方；关闭时不占空间。

## 窄宽度行为

- 扩展内容按 180px 宽度仍可操作进行设计，并测试 180、240、300 和 360px。
- 不设置会撑宽页面的 `min-width`。
- 所有网格轨道使用 `minmax(0, 1fr)`，标题和输入框允许收缩。
- 关闭按钮、设置按钮和图标使用稳定尺寸，不因标题长度改变布局；固定标签额外图钉只占自身宽度。
- 快捷网站设置对话框在窄宽度下使用视口宽度并纵向滚动。
- Chrome Side Panel 本身可拖动到的最小宽度由 Chrome 控制，扩展 API 无法修改；本变更只确保扩展内容不会额外抬高最小宽度。

## 结构调整

页面结构从“顶部搜索工具栏 + 标签列表”调整为：

```text
侧边栏外壳
  可选快捷网站区
  可滚动标签列表
  状态信息（仅有消息时显示）
  固定底部工具栏
    搜索框
    设置按钮
```

`TabStore`、Chrome 标签事件和搜索数据流保持不变。主要修改范围为 `index.html`、`sidebar.css`、`tab-renderer.ts`、对应测试，以及 favicon CSP 和发布检查。

## 性能要求

- 不增加框架、轮询或内容脚本。
- 标签行仍使用增量 patch，标题或 active 状态变化时不重建 favicon 节点。
- 100 个标签页时滚动和搜索保持流畅。
- 隐藏域名只改变渲染，不删除搜索所需数据。

## 验收标准

- 30px 左右的单行标签列表，不显示链接或域名。
- 标签行之间没有分割线。
- 固定标签排在最前面，行首显示图钉且不出现“固定”中文。
- 在同等高度下明显多于原 46px 双行布局的可见标签数量。
- 搜索框与设置按钮始终固定在底部。
- 180px 内容宽度下无水平溢出、文本遮挡或控件裁切。
- HTTPS `favIconUrl` 能显示；失败时显示首字符。
- 键盘焦点、关闭按钮、固定状态和 active 状态仍清晰可用。
- 重新构建并生成新的 Chrome 安装目录和 ZIP 包。
