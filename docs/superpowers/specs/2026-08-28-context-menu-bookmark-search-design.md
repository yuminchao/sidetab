# 右键菜单、收藏夹与搜索体验优化设计

## 背景

当前标签页和分组右键菜单会把部分不可执行操作置灰，内容树关闭时仍可能出现树相关操作。网页悬浮球的搜索结果虽然复用了侧边栏的搜索数据，但字体、字号和来源展示方式不一致。两个搜索入口在没有本地记录匹配时，按 Enter 也不会继续使用浏览器搜索。

本次改动统一这些交互，并在标签页右键菜单增加“添加到收藏夹”。

## 目标

1. 标签页与分组右键菜单只显示当前可以执行的操作，不显示置灰项。
2. 内容树关闭时，标签页菜单不显示任何内容树操作。
3. 标签页菜单支持将当前网页添加到 Chrome 收藏夹；已收藏的网址不重复添加。
4. 侧边栏和悬浮球搜索在没有本地匹配结果时，允许按 Enter 使用 Chrome 默认搜索引擎搜索输入内容。
5. 悬浮球搜索结果的字体、字号和来源胶囊与侧边栏搜索结果一致。
6. 保持现有键盘导航、菜单定位、忙碌保护、错误恢复和本地隐私边界。

## 非目标

- 不增加收藏夹目录选择器、编辑收藏名称、取消收藏或收藏夹管理界面。
- 不缓存或遍历完整收藏夹树，不增加收藏夹事件监听器。
- 不允许用户配置固定搜索引擎；网页搜索始终使用 Chrome 当前默认搜索引擎。
- 不重构整个侧边栏或替换现有菜单 DOM 架构。

## 方案选择

采用“菜单动作可见性模型”：保留现有预创建菜单节点，在每次打开菜单时根据最新上下文设置 `hidden`，并统一整理分隔线和键盘焦点。

未采用以下方案：

- 仅使用 CSS 隐藏 `disabled`：会保留不准确的无障碍状态，且无法可靠处理空分区、子菜单和焦点。
- 每次打开时重建全部菜单 DOM：结构更纯粹，但会扩大现有事件绑定和键盘逻辑的改动面。

## 标签页右键菜单

### 可见性

菜单上下文继续由内存中的标签、分组、快捷网站、内容树和忙碌状态计算。原来设置为禁用的主菜单动作改为隐藏：

- `duplicate`：当前标签不可复制或相关状态尚未就绪时隐藏。
- `open-all-shortcuts`：没有可打开的快捷网站时隐藏。
- `add-to-group`、`remove-from-group`、同网站分组、一键分组：当前状态不允许执行时隐藏。
- `dissolve-tree`、`delete-subtree`：内容树关闭、标签不是可操作树节点或树状态尚未就绪时隐藏。
- `close-below`、`close-above`、`close-same-site`：没有符合条件的目标标签时隐藏。
- `restore-recently-closed`：没有最近关闭会话时隐藏。
- `add-bookmark`：URL 不支持收藏、已经收藏或收藏状态查询失败时隐藏。

固定/取消固定、设为快捷网站等没有现有不可用条件的动作保持可见。菜单打开后，键盘只遍历可见动作。

### 分隔线

菜单项保持现有分区顺序，但分隔线不再具有独立业务状态。每次同步可见性后，从 DOM 顺序重新计算：

- 分隔线前后必须都存在可见菜单项。
- 连续分隔线只保留一个。
- 菜单开头和结尾不显示分隔线。

因此隐藏整个内容树分区、分组分区或关闭分区时，不会留下空白分隔线。

### 添加到收藏夹

新增菜单动作“添加到收藏夹”。菜单打开前对当前标签的完整 URL 调用一次 `chrome.bookmarks.search({ url })`：

- 仅接受 `http:` 或 `https:` URL。
- 查询返回存在相同完整 URL 的书签时隐藏动作。
- 查询返回空数组时显示动作。
- 查询失败时仍打开其他菜单项，但隐藏收藏动作，不显示错误提示。

用户点击后使用当前标签最新标题和 URL 调用 `chrome.bookmarks.create({ title, url })`。执行期间沿用标签操作忙碌保护；成功后关闭菜单。创建失败时通过现有操作状态区域显示“添加收藏夹失败”，不修改本地视图。收藏夹由 Chrome 选择默认创建位置，本次不指定 `parentId`。

异步 URL 查询使用打开代次标识。查询完成前如果用户滚动、调整窗口、打开另一菜单或目标标签消失，则旧结果不得打开菜单或覆盖新菜单状态。

## 分组右键菜单

分组菜单同样只展示可执行项：

- 分组处于忙碌状态时不打开菜单，因为所有修改动作都不可执行。
- 空分组或关闭条件不满足时隐藏“关闭分组”。
- 颜色子菜单隐藏当前颜色，而不是将当前颜色置灰。
- 分组不忙碌且仍存在时，“在分组中新建标签页”“重命名分组”“修改颜色”和“解散分组”保持可见；分组在打开前消失时不显示菜单。

分组菜单和颜色子菜单的键盘导航仅遍历可见项。主菜单没有可见项时不显示；分隔线按与标签页菜单相同的规则整理。

## 搜索无结果回退

### 触发条件

侧边栏底部搜索框和网页悬浮球搜索框采用相同规则：

- 输入去除首尾空白后必须非空。
- 最新一轮收藏夹和历史记录查询已经完成。
- 最新结果数组为空。
- 用户按下 Enter。

满足条件时调用 `chrome.search.query({ text, disposition: "NEW_TAB" })`，通过 Chrome 当前默认搜索引擎在新标签页搜索。成功后清空并关闭当前搜索面板。

以下情况不得触发网页搜索：

- 查询仍在进行。
- 有本地结果；此时 Enter 打开当前选中结果。
- 输入为空。
- 当前按键属于过期查询或已销毁控制器。

### 侧边栏调用

`history-search.ts` 增加明确的 `onSearchWeb(query)` 回调，不直接依赖全局 Chrome API。`sidebar.ts` 将其绑定到 `chrome.search.query()`，便于单元测试并保持模块边界。

### 悬浮球调用

内容脚本不能直接使用 `chrome.search`。消息协议增加 `floating-ball/search-web` 请求，Service Worker 校验发送方和非空查询后调用 `chrome.search.query()`。成功或失败都返回现有稳定响应结构。

网页搜索失败时保留输入和搜索面板，并显示“无法打开浏览器搜索”，允许用户修改内容或重试。

## 悬浮球搜索结果视觉

悬浮球结果项改为与侧边栏相同的三列结构：标题区域和右侧来源胶囊；现阶段不新增图标下载或 favicon 展示。

- 字体族：`"Segoe UI", "Microsoft YaHei", system-ui, sans-serif`。
- 字号：`13px`。
- 标题：单行、省略溢出、最小宽度为零。
- 来源：`11px`、18px 高、左右 6px 内边距、9px 圆角。
- “收藏夹”使用蓝色浅底和深蓝文字。
- “历史记录”使用中性浅底和次级文字。

胶囊由独立 `span` 表示，设置 `data-source="bookmark"` 或 `data-source="history"`。不再把来源拼接进标题文本。

## 权限、隐私与文档

`manifest.json` 新增 `search` 权限，仅用于用户在无本地结果时主动按 Enter 调用 Chrome 默认搜索引擎。该权限不会读取默认搜索引擎配置或搜索结果内容。

收藏功能复用现有 `bookmarks` 权限，只对当前标签完整 URL 进行精确查询并创建单个书签，不遍历收藏夹树、不缓存收藏夹内容、不注册监听器。

同步更新：

- `README.md` 权限和功能说明。
- `docs/chrome-web-store-checklist.md` 的 `search` 权限理由。
- `docs/privacy-policy.md` 的搜索回退、收藏创建和权限用途。
- `update.log` 的版本更新内容；版本号在实际打包任务中按发布要求确定。

## 错误与并发

- 收藏状态查询失败：隐藏收藏动作，其他菜单正常使用。
- 收藏创建失败：保留 Chrome 真实状态，显示一次受控错误。
- 网页搜索失败：保留输入和面板，显示一次受控错误。
- 菜单打开、收藏查询和搜索查询都使用代次或现有生命周期标识，过期异步结果不得更新 UI。
- 操作执行期间复用现有忙碌集合，避免重复提交。

## 测试策略

### 标签页菜单

- 内容树关闭时不存在树相关可见项。
- 每一种 `can* = false` 的动作被隐藏而不是禁用。
- 隐藏分区后不出现首尾或连续分隔线。
- 已收藏、URL 不支持和查询失败时隐藏“添加到收藏夹”。
- 未收藏时显示并派发添加收藏命令。
- 过期收藏查询不能打开旧菜单。
- 键盘导航跳过所有隐藏项。

### 分组菜单

- 忙碌分组不打开菜单。
- 不可关闭分组隐藏“关闭分组”。
- 颜色子菜单隐藏当前颜色。
- 分隔线和键盘焦点仅基于可见项。

### 收藏执行

- 精确 URL 查询只调用一次。
- 创建书签使用最新标题和 URL。
- 成功不提前修改状态；失败显示受控错误且不重复创建。

### 搜索

- 两个搜索框在非空、查询完成且无结果时按 Enter 调用默认搜索引擎。
- 查询中、空输入和有结果时不触发网页搜索。
- 有结果时 Enter 保持打开选中本地结果。
- 网页搜索失败保留输入并显示错误。

### 视觉与产物

- 悬浮球结果 DOM 包含标题和独立来源胶囊。
- 悬浮球 CSS 包含与侧边栏一致的字体、字号和两类胶囊样式。
- Manifest、构建产物和发布文件包含 `search` 权限与更新后的内容脚本。

## 验收标准

1. 任意右键菜单中看不到不可执行的灰色按钮，也没有多余分隔线。
2. 内容树关闭时，标签页菜单不显示“解散树节点”或“删除树节点及子标签”。
3. 未收藏的 HTTP/HTTPS 标签可通过右键菜单添加到收藏夹，已收藏标签不显示该动作。
4. 侧边栏和悬浮球在无本地匹配时按 Enter，均使用 Chrome 默认搜索引擎打开新标签页。
5. 悬浮球搜索结果的标题文字和来源胶囊与侧边栏保持一致。
6. 类型检查、全量测试、构建检查和扩展打包均通过。
