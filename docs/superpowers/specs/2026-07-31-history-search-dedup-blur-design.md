# 历史记录搜索去重与失焦收起设计

## 背景

SideTab Lite 0.8.0 的历史记录搜索会读取最近 200 条记录，按规范化后的完整 URL 精确去重，再展示最多 20 条。该规则会把同一页面携带不同查询参数、跟踪参数、锚点或协议的访问记录视为不同结果，导致重复内容仍占据较多展示位置。

同时，结果框目前会在按下 `Esc`、按下 `Tab`、点击外部、打开设置或成功打开结果后收起，但搜索框通过其他方式失去焦点时不一定收起。

## 目标

- 历史记录按“主机名及端口 + 路径”去重。
- 忽略 HTTP/HTTPS 协议差异、全部查询参数、锚点和路径末尾斜杠差异。
- 将候选数量从 200 提高到 500，去重后最多返回 20 条。
- 搜索框失去焦点时收起结果，同时保证鼠标点击结果仍能正常打开页面。
- 不新增权限，不持久化历史记录或搜索结果。
- 随 0.8.1 版本发布。

## 非目标

- 不合并不同子域名、端口或实际路径。
- 不修改历史记录标题、排序或 Chrome 返回的时间顺序。
- 不删除 Chrome 中的历史记录。
- 不改变标签页列表、快捷网站或 favicon 缓存行为。
- 不在本设计中实现“启动时恢复侧边栏”；该功能使用独立设计和实施计划。

## 去重规则

历史记录仍先通过 `new URL(item.url)` 解析，并只接受 HTTP 和 HTTPS 地址。展示结果保留 Chrome 返回的第一条记录及其完整规范化 URL，实际打开时仍使用该 URL，包括原有查询参数和锚点。

为每条有效记录生成独立去重键：

1. 使用 `URL.host` 作为主机部分，使主机名大小写和默认端口遵循标准 URL 规范化，同时保留显式非默认端口。
2. 使用 `URL.pathname` 作为路径部分，保持路径大小写和编码差异。
3. 对非根路径删除所有末尾斜杠；根路径固定为 `/`。
4. 去重键不包含协议、用户名、密码、查询参数或锚点。

示例：

| URL | 去重结果 |
| --- | --- |
| `http://example.com/page` | 与下一行相同 |
| `https://example.com/page/?utm_source=a#top` | 与上一行相同 |
| `https://example.com/Page` | 不同，路径大小写保留 |
| `https://docs.example.com/page` | 不同，子域名保留 |
| `https://example.com:8443/page` | 不同，非默认端口保留 |
| `https://example.com/other` | 不同，路径保留 |

## 查询与数据流

`searchHistory` 每次调用 `chrome.history.search` 时使用：

```ts
{ text, startTime: 0, maxResults: 500 }
```

随后按 Chrome 返回顺序处理候选：

1. 解析并过滤无效或非 HTTP/HTTPS 地址。
2. 生成展示结果和去重键。
3. 若去重键已出现则跳过。
4. 首次出现时保存去重键并加入结果。
5. 获得 20 条唯一结果后立即停止处理。

候选数组仅在一次查询期间存在，不写入 `chrome.storage`，查询完成后由运行时回收。

## 失焦行为

历史搜索控制器监听输入框的 `blur` 事件。失焦后安排一个零延迟关闭任务，使同一轮鼠标操作中的结果项 `click` 可以先执行：

- 点击历史结果：结果打开逻辑先运行并关闭结果框，延迟任务随后成为无操作。
- 点击设置或页面其他位置：现有外部指针处理可以立即关闭，延迟任务不得产生额外状态变化。
- 通过键盘或脚本移走焦点：延迟任务关闭结果框。
- 关闭任务执行前重新聚焦搜索框：取消待执行关闭，保留或重新加载当前查询结果。
- 控制器销毁：清除查询防抖定时器和失焦关闭定时器，销毁后不得修改 DOM。

结果框收起后继续保留输入内容；再次聚焦时按现有行为重新查询该内容。

## 错误处理

- Chrome 历史查询失败时继续显示“无法读取历史记录”。
- 无效 URL 或非 HTTP/HTTPS URL 被忽略，不占结果名额。
- 打开历史结果失败时继续使用现有状态提示。
- 失焦关闭不抛出错误，也不改变正在执行的标签页创建请求。

## 测试

自动化测试覆盖：

- 查询参数、锚点、HTTP/HTTPS 和末尾斜杠差异会合并。
- 子域名、非默认端口、不同路径和路径大小写不会合并。
- 重复记录保留 Chrome 返回的第一条完整 URL 和标题。
- 查询参数使用 `maxResults: 500`，去重后仍最多返回 20 条。
- 无效记录不占结果名额。
- 搜索框通过鼠标、键盘和脚本失焦时收起结果框。
- 点击历史结果造成的失焦不会阻止页面打开。
- 重新聚焦和控制器销毁会正确清理待执行的关闭任务。
- 完整历史搜索、Sidebar、类型检查、构建和发布测试继续通过。
