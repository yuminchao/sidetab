# 新建标签页 SVG 图标设计

## 背景

SideTab Lite 当前在标签列表末尾使用文字字符“+”作为新建标签页按钮内容。按钮虽然通过网格布局居中行框，但不同系统字体的字形上下留白不同，导致加号在 44×24 像素按钮内无法稳定实现视觉垂直居中。

用户提供了 `C:\Users\NUC\Downloads\新增按钮.svg`，要求用该图标替换文字加号。源文件 SHA-256 为：

```text
D2B0751EA0B01D06D1BF9B7D821B6F6325E1477D360C9B640D7D61125FB673D5
```

该 SVG 自带方框和加号，因此应替代现有按钮边框，不能与外层边框叠加。

## 目标

- 使用用户提供的本地 SVG 替换新建标签页按钮中的文字加号。
- 图标以 18×18 像素在 44×24 像素点击区域内精确居中。
- SVG 自带方框替代按钮原有边框，避免双层边框。
- 保留按钮现有位置、标签列表滚动行为、点击逻辑和无障碍名称。
- 图标使用当前文字颜色，适配浅色、深色、悬停、按下、焦点和禁用状态。
- 将图标纳入发布白名单与 SVG 安全审计，0.8.1 发布包精确包含 15 个文件。

## 非目标

- 不改变新建标签页的 Chrome API 调用、请求防重或错误提示。
- 不改变按钮的 44×24 像素点击区域及其在列表末尾的位置。
- 不改变标签列表、滚动容器或空状态布局。
- 不生成新的位图或首字母图标。
- 不在本设计中实现历史搜索优化或启动时恢复侧边栏。

## SVG 清理

源文件包含 XML 声明、DOCTYPE、生成器时间、样式类、版本、`p-id`、额外命名空间和固定宽高。发布资源 `assets/icons/add-tab.svg` 的根元素固定为带 `xmlns="http://www.w3.org/2000/svg"` 和 `viewBox="0 0 1024 1024"` 的 `<svg>`，内部按源顺序保留两个 `<path>`。

两个 `<path>` 的完整 `d` 值必须与源文件完全一致。根元素只允许 `xmlns` 和 `viewBox`，路径只允许 `d`，不得保留 XML 声明、DOCTYPE、脚本、事件属性、远程引用、生成器属性、宽高或额外命名空间。

现有发布审计对搜索、设置和网络兜底图标使用单路径白名单。该审计需要扩展为按文件声明允许的路径数量：`add-tab.svg` 必须且只能包含两个合法 `<path>`，其他已清理 SVG 的既有约束不得放宽。

## 标记与样式

`#new-tab-button` 继续使用原生 `<button type="button">`，保留 `title="新建标签页"` 和 `aria-label="新建标签页"`。删除按钮内部可见文字“+”，避免图标和文本同时显示。

按钮保持：

- 宽度 44px。
- 高度 24px。
- 列表末尾 3px 上下外边距。
- 网格居中布局。
- 当前滚动容器中的文档流位置。

按钮默认移除外层边框、背景和圆角。`::before` 创建固定 18×18 像素图标：

```css
background-color: currentColor;
-webkit-mask: url("../assets/icons/add-tab.svg") center / contain no-repeat;
mask: url("../assets/icons/add-tab.svg") center / contain no-repeat;
```

由于伪元素本身由网格布局居中，图标不会受字体度量、字号或行高影响。按钮继续保留现有悬停和按下背景反馈、键盘焦点轮廓以及禁用颜色和光标状态。

## 交互与无障碍

- 左键点击仍只创建并激活一个新标签页。
- 请求期间按钮继续禁用，防止重复创建。
- 空标签列表时按钮仍可见且可用。
- 图标是装饰内容，不单独暴露给辅助技术；按钮名称仍来自 `aria-label`。
- 禁用时 `currentColor` 使用现有 `GrayText`，图标无需单独切换资源。

## 测试

自动化测试覆盖：

- 清理后的 `add-tab.svg` 存在且只含两个仅有 `d` 属性的 `<path>`。
- SVG 不包含 XML、DOCTYPE、脚本、事件、远程引用和生成器元数据。
- 新建标签页按钮不再包含可见“+”文本，无障碍名称保持“新建标签页”。
- 按钮仍为 44×24 像素，伪元素固定 18×18 像素并使用本地图标 mask。
- 按钮默认无外层边框和背景，不产生双层方框。
- 悬停、按下、焦点和禁用规则继续存在。
- 点击、防重、空状态和滚动行为的既有测试继续通过。
- 发布白名单、dist 审计和 ZIP 精确包含 `assets/icons/add-tab.svg` 在内的 15 个文件。
