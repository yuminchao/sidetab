# 同类网站标签批量关闭与快速分组设计

## 背景

SideTab Lite 已支持标签复制、固定、加入分组、移出分组、关闭下方标签页和恢复最近关闭标签页。用户在同一窗口打开多个来自同一网站的页面时，仍需要逐个关闭或逐个加入分组。本次变更在标签右键菜单中增加两个批量动作：关闭其他同类网站标签页，以及快速分组同类网站。

本功能继续遵循性能优先和 Chrome 状态优先原则。目标集合只从现有 `TabStore` 内存快照计算，不增加标签查询、长期索引、轮询或事件监听器；操作完成后的界面仍由 Chrome 标签与分组事件同步。

## 目标

- 在标签右键菜单中新增“快速分组同类网站”。
- 在标签右键菜单中新增“关闭其他同类网站标签页”。
- 按完全相同的 HTTP/HTTPS `hostname` 判定同类网站。
- 批量关闭时保留右键目标标签和所有固定标签。
- 快速分组时只处理未固定且未分组的同类标签。
- 菜单打开时判断可用状态，执行时基于最新快照重新计算目标。
- 批量动作使用最少的 Chrome API 调用，不增加权限和持久化状态。
- 保持新增标签按钮中的文本加号水平、垂直居中，并增加回归验证。

## 非目标

- 不按主域名合并不同子域名。
- 不把 `www.example.com` 与 `example.com` 视为同类。
- 不处理 `chrome://`、`file://`、扩展页面或其他非 HTTP/HTTPS 标签。
- 不关闭右键目标标签或任何固定标签。
- 不移动已属于其他分组的标签。
- 不为批量关闭增加确认弹窗、撤销入口或数量提示。
- 不为快速分组打开名称和颜色对话框。
- 不重新引入 `add-tab.svg`，不使用定位偏移修正加号。
- 不维护 hostname 到标签 ID 的长期缓存。
- 不在执行前调用 `chrome.tabs.query()`。

## 同类网站判定

新增独立纯函数模型，从 `TabViewModel.url` 解析标准 `URL`：

1. 协议必须是 `http:` 或 `https:`。
2. 使用解析后的 `URL.hostname` 作为网站标识。
3. 两个标签的 `hostname` 完全相同才属于同类。
4. 协议和端口不参与比较，因此同一 hostname 的 HTTP 与 HTTPS 页面属于同类，不同端口也属于同类。
5. 子域名参与比较，因此 `docs.google.com` 与 `mail.google.com` 不属于同类。
6. 不移除 `www.` 前缀。
7. URL 无法解析或 hostname 为空时，不提供同类批量动作。

`URL.hostname` 的标准化结果作为分组名称。模型不读取 DOM、不调用 Chrome API、不修改输入数组。

## 目标集合

### 关闭其他同类网站标签页

输入为当前窗口完整标签快照和右键目标标签 ID。仅当目标标签是有效 HTTP/HTTPS 页面时继续计算。

关闭目标必须同时满足：

- ID 不等于右键目标标签 ID。
- hostname 与右键目标标签完全相同。
- `pinned === false`。

标签是否已分组不影响关闭资格。处于展开或折叠分组中的同类普通标签都属于关闭目标。结果按 `TabStore.list()` 顺序返回。

目标集合为空时，菜单项保持显示但禁用。右键目标本身即使是固定标签，也可以关闭其他符合条件的同类普通标签。

### 快速分组同类网站

右键目标标签必须同时满足：

- 是有效 HTTP/HTTPS 页面。
- `pinned === false`。
- `groupId` 表示未分组。

分组候选必须同时满足：

- hostname 与右键目标标签完全相同。
- `pinned === false`。
- 当前未加入任何分组。

候选集合包含右键目标标签。候选少于两个时，菜单项保持显示但禁用。已固定或已属于其他分组的同类标签不移动，也不计入最低数量。

## 右键菜单设计

主菜单顺序调整为：

1. 复制标签页。
2. 固定标签或取消固定。
3. 设为快捷网站。
4. 添加到分组。
5. 从分组中移除，仅在当前标签已分组时显示。
6. 快速分组同类网站。
7. 关闭下方标签页。
8. 关闭其他同类网站标签页。
9. 打开最近关闭标签页。

两个新菜单项使用原生 `button` 和 `role="menuitem"`。禁用状态使用原生 `disabled`；鼠标点击、`Enter` 和空格均不派发命令，上下方向键导航自动跳过禁用项。现有悬停、焦点、菜单定位、窗口缩放关闭、滚动关闭和 `Escape` 恢复焦点行为保持不变。

### 右键目标临时选中状态

右键菜单打开时，触发菜单的标签行增加临时 `data-context-selected="true"` 状态。鼠标右键和 `Shift+F10` 键盘触发使用相同行为。

临时选中状态使用完整的 1px 蓝色边框，与普通悬停使用的无边框 `ButtonFace` 背景明确区分。边框通过不占布局空间的内描边实现，不改变标签宽度、高度、网格列或文字位置。浅色主题使用 Chrome 蓝 `#1a73e8`，深色主题使用更高亮度的蓝色 `#8ab4f8`，确保边框可见。

该状态不使用浅色选中背景，不把完整边框缩减为单独的左侧 2px 强调线，也不模拟 Chrome 的真实激活状态。如果右键目标本身就是当前激活标签，完整蓝色边框与该标签原有的激活标识同时保留。选中期间关闭按钮保持可见。

二级分组菜单展开期间继续保持右键目标选中。以下任一情况发生时必须立即清除临时状态：

- 用户执行任意菜单命令。
- 点击菜单外部。
- 按 `Escape` 关闭菜单。
- 标签列表滚动或窗口缩放。
- 右键目标标签被关闭或替换。
- 右键菜单组件销毁。
- 在另一个标签上打开右键菜单；先清除旧目标，再选中新目标。

该状态只保存在当前标签行的临时 DOM 属性中，不写入 `TabStore`，不设置 `aria-selected`，不调用 Chrome API，也不持久化。菜单关闭方法统一负责清理，避免不同关闭路径遗留高亮。

菜单命令只携带右键目标标签 ID，不保存打开菜单时计算出的目标 ID 数组：

- `{ action: "group-same-site", tabId }`
- `{ action: "close-same-site", tabId }`

菜单打开时通过只读回调计算可用状态。用户点击后先关闭菜单，再由侧边栏控制器根据最新 `TabStore` 快照重新生成执行计划。

## 新增标签按钮居中约束

新增标签按钮继续使用文本 `+`，不使用 SVG、伪元素图标或绝对定位。按钮保持现有 44px × 24px 稳定尺寸、边框和随标签列表滚动的布局。

加号通过按钮自身的网格布局水平和垂直居中：

- 使用 `display: grid` 和 `place-items: center`。
- `padding: 0`，避免上下内边距影响字形位置。
- 使用稳定的按钮高度和 `line-height: 1`。
- 不使用 `top`、`transform: translateY()`、负 margin 或按平台区分的像素偏移。

该要求属于现有按钮的回归保护，不改变新建标签逻辑、滚动容器、按钮尺寸或边框样式。

## 架构与组件边界

### 同类网站纯函数模型

新增小型模型模块，负责：

- 从标签 URL 提取受支持的 hostname。
- 计算可关闭的其他同类标签 ID。
- 计算快速分组计划，包括 hostname、windowId 和候选标签 ID。

模型不依赖 `chrome`、`document`、存储或控制器状态，便于边界测试和性能测试。

### 右键菜单

`tab-context-menu` 只负责展示两个新菜单项、设置禁用状态、键盘导航和派发轻量命令，不负责保存或执行批量计划。

### 标签动作层

标签动作层新增专用的同类标签批量关闭动作。目标为空时直接返回，否则只调用一次：

```ts
chrome.tabs.remove(tabIds)
```

动作失败时统一抛出“无法关闭其他同类网站标签页”。不逐个关闭，不提前修改 `TabStore`。

### 分组动作层

分组动作层新增批量创建方法，先调用一次：

```ts
chrome.tabs.group({
  tabIds,
  createProperties: { windowId },
})
```

取得 `groupId` 后调用一次：

```ts
chrome.tabGroups.update(groupId, {
  title: hostname,
  color: "grey",
})
```

不打开现有新建分组对话框。成功后不直接修改分组存储或 DOM，等待现有 Chrome 标签与分组事件更新真实状态。

### 侧边栏控制器

侧边栏负责在命令执行瞬间重新计算计划，并复用现有状态提示、生命周期保护和失败重同步机制。

快速分组开始前检查本次全部候选标签是否正在进行其他分组操作。若均空闲，则把全部候选 ID 暂时加入现有分组忙碌集合；操作完成或失败后一次性释放。菜单可用状态也检查该集合，避免同一批标签重复提交。

## 并发与状态同步

- 菜单打开后标签可能创建、关闭、固定、移动、变更 URL 或加入分组，因此执行命令时必须重新计算。
- 重新计算后无关闭目标或无有效分组计划时静默结束，不调用 Chrome API。
- 批量关闭期间不提前移除列表行，继续由 `tabs.onRemoved` 逐项同步。
- 快速分组期间不提前改变标签 `groupId` 或插入分组标题，继续由 `tabs` 和 `tabGroups` 事件同步。
- 快速分组失败后执行一次现有标签与分组快照重同步，以 Chrome 当前状态为准，不循环重试。
- 批量关闭与快速分组不阻塞标签创建、更新、激活或关闭事件。
- 侧边栏销毁后，迟到的异步结果不得更新状态或 DOM。

## 错误处理

- `chrome.tabs.remove()` 失败：显示“无法关闭其他同类网站标签页”。
- `chrome.tabs.group()` 失败：显示“无法快速分组同类网站”。
- 分组已创建但 `chrome.tabGroups.update()` 失败：保留 Chrome 已创建的默认分组，显示“分组已创建，但无法保存名称或颜色”，并触发一次真实状态重同步。
- 执行时右键目标已不存在、URL 已变为不支持类型或候选数量不足：静默结束。
- 状态重同步失败：保留当前可用视图和现有错误提示，不重试、不轮询。

## 性能与内存

- 菜单打开时最多进行一次 O(n) 内存扫描。
- 命令执行时最多再进行一次 O(n) 内存扫描。
- 不新增 `chrome.tabs.query()`、`chrome.tabGroups.query()` 或其他读 API 调用。
- 不新增 hostname 索引、结果缓存、定时器、轮询或事件监听器。
- 批量关闭无论目标数量多少都只调用一次 `chrome.tabs.remove()`。
- 快速分组无论候选数量多少都只调用一次 `chrome.tabs.group()` 和一次 `chrome.tabGroups.update()`。
- 临时数组和集合只存活于菜单判断或单次操作期间，操作完成后可回收。
- 500 个标签下的计算保持线性，不增加常驻内存。

## 权限与隐私

本功能只使用现有 `tabs` 和 `tabGroups` 权限，不新增权限、主机权限、content script、网络请求或数据持久化。hostname 只在本地内存中用于当前窗口标签匹配和分组命名，不上传、不记录到日志、不写入扩展存储。

## 测试策略

### 纯函数模型

- 完全相同 hostname 正确匹配。
- HTTP 与 HTTPS 的相同 hostname 正确匹配。
- 不同端口的相同 hostname 正确匹配。
- `www.example.com` 与 `example.com` 不匹配。
- 不同子域名不匹配。
- `chrome://`、`file://`、扩展页面、空 URL 和无效 URL 均不生成计划。
- 关闭计划保留当前标签和所有固定标签，但包含已分组的普通标签。
- 分组计划只包含未固定且未分组的同类标签，并要求至少两个候选。
- 输入列表不被修改，结果顺序稳定。
- 500 个标签的单次计算保持线性，并且不依赖 Chrome API。

### 右键菜单

- 验证新增菜单文字、顺序和 `role`。
- 有目标时派发正确的轻量命令。
- 无目标时菜单项禁用，鼠标和键盘均不派发命令。
- 上下方向键跳过禁用项并保持循环导航。
- `Shift+F10`、悬停、`Escape`、滚动、窗口缩放和销毁行为保持正确。
- 鼠标右键和 `Shift+F10` 打开菜单时，只给触发标签增加临时选中属性。
- 临时选中使用完整的 1px 蓝色内描边，与普通悬停不同，并且不造成标签尺寸或内容位移。
- 浅色主题使用 `#1a73e8`，深色主题使用 `#8ab4f8`；临时选中不增加额外背景色。
- 二级菜单展开时保持选中；命令执行、外部点击、`Escape`、滚动、缩放、目标移除、切换目标和销毁时清除。
- 临时选中期间关闭按钮可见，且不修改 `TabStore`、`aria-selected` 或真实激活状态。

### 动作层与侧边栏

- 关闭多个目标只调用一次 `chrome.tabs.remove(ids)`。
- 关闭目标为空时不调用 API。
- 关闭失败显示稳定错误且不提前删除 DOM。
- 快速分组只调用一次 `chrome.tabs.group()` 和一次 `chrome.tabGroups.update()`。
- 自动分组名等于 hostname，颜色为灰色。
- 分组目标为空或不足两个时不调用 API。
- 菜单打开后状态变化时使用执行瞬间的最新快照。
- 分组涉及的全部标签在操作期间防止重复提交，并在成功或失败后释放。
- 分组创建失败和元数据更新部分失败均显示正确错误并只触发一次重同步。
- Chrome 事件到达前不提前修改标签或分组 DOM。
- 页面销毁后迟到结果不更新界面。

### 回归与视觉检查

- 运行类型检查、完整测试、构建、发布目录审计和标签渲染基准。
- 在 Chrome 最小侧边栏宽度和常规宽度检查九个菜单项不横向溢出，菜单可在视口内定位。
- 检查菜单悬停、禁用、焦点和键盘导航样式。
- 验证新增标签按钮仍为 44px × 24px、`padding: 0`，文本加号在按钮内水平和垂直居中。
- 验证新增标签按钮不引用 `add-tab.svg`，不使用 `top`、垂直 `transform` 或负 margin 修正字形位置。
- 在 Chrome 最小侧边栏宽度和常规宽度截图检查加号无上下偏移；按钮仍随标签列表滚动。
- 现有复制、固定、快捷网站、已有分组、关闭下方标签页和恢复最近关闭标签页行为保持不变。

## 发布要求

本功能不增加发布文件和权限。后续执行打包时必须提升当前版本号，并把本次新增的“关闭其他同类网站标签页”和“快速分组同类网站”记录到仓库根目录 `update.log`；发布 ZIP 继续只包含经过审计的扩展运行文件。

## 验收标准

- 用户可以从标签右键菜单一键关闭其他同 hostname 的普通标签，当前标签和固定标签始终保留。
- 用户可以把至少两个同 hostname、未固定且未分组的标签一键放入 hostname 命名的灰色新分组。
- 新增标签按钮的文本加号在所有支持宽度下保持水平、垂直居中。
- 右键菜单打开期间，触发标签显示完整的 1px 蓝色临时选中边框，且无尺寸跳动；菜单关闭后立即恢复。
- 快速分组不会移动已固定、已分组或非 HTTP/HTTPS 标签。
- 批量关闭不会关闭当前标签、固定标签或非 HTTP/HTTPS 同协议分类；已分组的同 hostname 普通标签仍按规则关闭。
- 菜单禁用状态、鼠标和键盘操作符合现有可访问性行为。
- 执行时使用最新内存快照，不增加标签查询、缓存、监听器或权限。
- 批量 API 调用次数固定，失败反馈和部分成功恢复明确。
- 自动化测试、性能基准、构建和发布审计全部通过。
