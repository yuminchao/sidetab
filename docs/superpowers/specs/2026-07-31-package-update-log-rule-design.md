# 打包更新日志规则设计

## 背景

项目现有打包规则已经要求记录版本号和更新内容，但没有明确所有版本必须持续写入同一个文件，可能被理解为允许按版本创建多个日志文件。

## 规则

修改项目根目录的 `AGENTS.md`，将打包记录规范明确为：

> 每次打包时，必须将版本号及对应的更新内容追加记录到固定文件 `E:\java\sidebar\update.log` 中；所有版本共用该文件，不得按版本新建其他更新日志文件。

## 范围

- 仅修改项目规范，不执行打包。
- 本次不创建或修改 `update.log`。
- 不调整其他开发、数据库或 Git 规则。

## 验收条件

- `AGENTS.md` 明确指定唯一日志文件为 `E:\java\sidebar\update.log`。
- 规则明确要求使用追加方式记录。
- 规则明确禁止按版本创建其他更新日志文件。
