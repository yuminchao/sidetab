# 关闭下方标签页设计

## 背景

SideTab Lite 当前支持复制标签页、固定或取消固定标签页，以及将标签页设为快捷网站。为提高批量整理标签页的效率，右键菜单新增“关闭下方标签页”命令。

本功能以性能优先，不增加标签查询请求，不提前修改本地标签状态，并沿用现有 Chrome 标签事件同步机制。

## 目标

- 在标签页右键菜单中新增“关闭下方标签页”。
- 按侧边栏当前顺序批量关闭当前标签下方的普通标签页。
- 始终保留当前标签和所有固定标签页。
- 没有可关闭目标时显示禁用菜单项。
- 批量关闭失败时显示明确且稳定的错误信息。

## 非目标

- 不关闭当前标签。
- 不关闭任何固定标签页。
- 不增加二次确认弹窗、撤销入口或关闭数量提示。
- 不在操作前重新调用 `chrome.tabs.query`。
- 不提前从侧边栏移除待关闭标签。

## 交互设计

右键菜单从上到下排列为：

1. 复制标签页
2. 固定标签或取消固定
3. 设为快捷网站
4. 关闭下方标签页

“下方”以 `TabStore` 当前列表顺序为准。目标集合为当前标签之后所有 `pinned === false` 的标签页。当前标签即使未固定也不属于目标；位于当前标签之后的固定标签页同样不属于目标。

如果目标集合为空，“关闭下方标签页”保持显示但处于禁用状态。禁用项不响应鼠标、`Enter` 或空格，方向键导航跳过禁用项。菜单继续沿用现有悬停、焦点和按下反馈。

## 架构与数据流

### 菜单命令

`TabContextCommand` 新增 `close-below` 命令，只携带当前标签 ID。`createTabContextMenu` 通过回调查询该标签当前是否存在可关闭的下方普通标签，从而设置菜单项的禁用状态。

点击命令后，菜单先关闭，再把 `{ action: "close-below", tabId }` 交给侧边栏控制器。侧边栏在执行时基于最新 `TabStore` 重新计算目标 ID，避免使用打开菜单时的过期数组。

### 批量关闭

侧边栏只调用一次 `chrome.tabs.remove(tabIds)`。目标为空时直接返回，不调用 Chrome API。批量关闭成功后不直接修改 `TabStore` 或 DOM，继续由现有 `tabs.onRemoved` 事件逐项同步真实状态。

这种方式不会增加 `tabs.query` 往返，关闭多个标签时也不会产生逐个 `remove` 调用，符合性能优先原则。

## 并发与错误处理

- 菜单打开后标签顺序可能变化，因此执行命令时必须重新基于 `TabStore` 计算目标。
- 如果执行时目标已全部消失，则静默结束。
- `chrome.tabs.remove` 拒绝时，在现有状态区域显示“无法关闭下方标签页”。
- 失败时不提前移除任何本地标签行；后续真实 Chrome 事件仍可正常更新界面。
- 批量关闭期间不锁定标签列表，标签创建、更新、移动、关闭事件继续正常处理。
- 侧边栏销毁后，未完成操作不得更新状态或 DOM，沿用现有生命周期保护。

## 可访问性

- 新菜单项使用原生 `button` 和 `role="menuitem"`。
- 禁用状态使用原生 `disabled`，便于辅助技术识别。
- 上下方向键只在可用菜单项之间循环。
- `Shift+F10`、`Escape`、`Enter` 和空格行为与现有菜单保持一致。

## 测试策略

### 菜单测试

- 验证四个菜单项的文字和顺序。
- 有目标时派发 `close-below` 命令。
- 无目标时菜单项禁用，鼠标与键盘均不派发命令。
- 方向键跳过禁用项并保持循环导航。

### 侧边栏测试

- 普通标签触发时，只关闭其下方普通标签。
- 固定标签触发时，保留后续固定标签，只关闭下方普通标签。
- 当前标签始终保留。
- 目标为空时不调用 `chrome.tabs.remove`。
- 使用命令执行瞬间的最新 `TabStore` 顺序。
- 只发出一次批量 `remove`，且不额外调用 `tabs.query`。
- 批量关闭失败时显示“无法关闭下方标签页”。
- 真实 `onRemoved` 事件到达前不提前删除列表行。

### 回归与发布

- 运行类型检查和全部测试。
- 在常规宽度与最窄侧边栏宽度检查四项菜单不溢出。
- 更新 README、Chrome Web Store 检查清单及相关权限说明；本功能不增加权限。
- 发布版本升级为 `0.5.0`，重新生成并审计 Chrome Web Store ZIP。

## 验收标准

- 用户可以从任意标签页右键菜单执行“关闭下方标签页”。
- 操作只影响当前标签之后的普通标签页。
- 当前标签和所有固定标签页均保留。
- 无目标时菜单项明确禁用且键盘导航正确。
- 批量关闭只调用一次 Chrome API，失败反馈稳定。
- 所有自动化测试、构建和发布产物审计通过。
