# Chrome 标签分组与中键关闭设计

## 背景

SideTab Lite 当前只展示扁平标签列表。Chrome 原生标签分组的名称、颜色、折叠状态和标签归属没有进入侧边栏，用户也无法从侧边栏创建分组或调整分组归属。同时，标签行尚不支持与 Chrome 顶部标签栏一致的鼠标中键关闭操作。

本功能接入 Chrome 原生分组状态，不建立扩展私有分组。Chrome 官方要求使用 `chrome.tabGroups` 读取和修改分组元数据，使用 `chrome.tabs.group()` 与 `chrome.tabs.ungroup()` 修改标签归属。

参考：

- [chrome.tabGroups API](https://developer.chrome.com/docs/extensions/reference/api/tabGroups)
- [chrome.tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs)

## 目标

- 按 Chrome 当前窗口的真实顺序展示固定标签、未分组标签和分组标签。
- 展示分组名称、颜色和折叠状态，并与 Chrome 原生分组双向同步。
- 在标签右键菜单中创建分组、加入已有分组和移出分组。
- 支持标签跨分组、未分组区域和固定区域拖动。
- 支持鼠标中键关闭标签。
- 使用用户提供的搜索与设置 SVG 优化底部搜索框，并让搜索框撑满底部宽度。
- 保持增量更新、低 DOM 数量和事件驱动架构。
- 将扩展版本升级为 `0.7.0`。

## 非目标

- 不提供分组标题右键菜单。
- 不提供分组重命名、修改颜色、关闭整组或取消整组的标题行操作。
- 不支持直接拖动整个分组标题排序。
- 不建立本地分组配置，不跨设备同步扩展私有状态。
- 不增加主机权限、content script 或后台常驻任务。

## 权限与兼容性

`manifest.json` 新增 `tabGroups` 权限。现有 `tabs` 权限继续用于读取标签敏感字段、分组和取消分组。最低 Chrome 版本保持 `114`，高于 `tabGroups` API 的最低可用版本。

`SidebarDependencies` 增加 `tabGroups` 依赖，测试使用假 API 注入，不直接访问全局对象。后台 service worker 不参与分组同步。

## 数据模型

### 标签模型

`TabViewModel` 增加 `groupId`，值来自 `chrome.tabs.Tab.groupId`。未分组使用 Chrome 的 `TAB_GROUP_ID_NONE`，不另造哨兵值。标签继续保留 `index`、`pinned`、`active` 和 favicon 等字段。

### 分组模型

新增 `TabGroupViewModel`：

- `id`
- `windowId`
- `title`
- `color`
- `collapsed`

新增独立 `GroupStore`，仅保存当前窗口分组。它负责初始化、创建、更新、移动和删除，不保存 UI 私有折叠状态。

### 联合展示模型

渲染前根据 `TabStore` 和 `GroupStore` 生成只读联合列表，条目类型为分组标题或标签。规则如下：

1. 固定标签始终位于最前面且不进入分组。
2. 普通标签按 Chrome 原始 `index` 排列。
3. 遇到某分组第一个标签时插入一次分组标题。
4. 未分组标签保留在原始位置，可以出现在两个分组之间。
5. 分组折叠时只输出标题，不输出组内标签 DOM。
6. 分组缺失或事件暂时乱序时，相关标签暂按未分组标签展示，后续分组事件到达后纠正。

## 分组标题

标题行显示：

- 折叠箭头
- Chrome 原生颜色圆点
- 分组名称

不显示标签数量。Chrome 分组标题为空时，侧边栏显示“未命名分组”，但不把该占位文字写回 Chrome。

点击分组标题调用 `chrome.tabGroups.update(groupId, { collapsed })`。侧边栏不提前持久化乐观状态，以 Chrome 返回值或事件为真实状态。标题行支持键盘激活，并提供包含名称和折叠状态的无障碍名称。

## 右键菜单

标签右键菜单保留现有复制标签、固定或取消固定、设为快捷网站和关闭下方标签页，并新增二级菜单“添加到分组”。

二级菜单内容：

1. “新建分组”。
2. 当前窗口已有分组列表，显示颜色圆点和名称。
3. 当前所属分组显示选中状态并禁用，避免重复操作。

已分组标签在一级菜单额外显示“从分组中移除”。二级菜单支持鼠标悬停、点击、左右方向键、上下方向键、Enter、Space 和 Escape。菜单根据可用空间自动向左或向上展开，滚动、窗口缩放、点击菜单外部或标签被删除时关闭全部菜单层级。

## 新建分组编辑框

点击“新建分组”后关闭右键菜单并打开独立小型对话框。对话框包含：

- 可为空的名称输入框。
- Chrome 原生 9 种颜色色板：灰、蓝、红、黄、绿、粉、紫、青、橙。
- 默认选择灰色。
- 取消和创建操作。

创建流程：

1. 调用 `chrome.tabs.group({ tabIds: tabId, createProperties: { windowId } })`。
2. 获得新 `groupId` 后调用 `chrome.tabGroups.update(groupId, { title, color })`。
3. 更新成功后关闭对话框并等待 Chrome 事件同步视图。

如果第一步失败，保留对话框和输入。若分组已创建但元数据更新失败，保留 Chrome 已创建的分组，重新读取其真实状态，并在对话框显示错误；用户可以再次提交名称和颜色。组件销毁后迟到的异步结果不得修改 DOM。

## 加入与移出分组

- 加入已有分组调用 `chrome.tabs.group({ tabIds: tabId, groupId })`。
- 移出分组调用 `chrome.tabs.ungroup(tabId)`。
- 分组操作期间防止同一标签重复提交。
- 失败时显示底部状态错误并重新查询当前窗口标签与分组，恢复真实状态。

## 跨分组拖动

拖动计划同时计算目标 `index`、固定状态和目标 `groupId`：

- 拖到分组标题：加入该组并放到组内末尾。
- 拖到标签前后：继承目标标签的固定状态与分组归属，并按落点排序。
- 拖到未分组区域：移出原分组并按落点排序。
- 固定标签拖入分组：先取消固定，再移动并加入分组。
- 分组标签拖到固定区：先移出分组，再移动并固定。

分组标题不可作为拖动源。操作期间禁用其他拖动。执行顺序由独立动作层封装，任一步失败都进行完整的当前窗口快照重同步，以 Chrome 状态为准。

折叠分组标题可以作为放置目标。标签加入折叠分组后从列表中隐藏，标题仍保留。

## 中键关闭

标签列表监听 `mousedown` 和 `auxclick`：

- `mousedown` 在鼠标中键命中标签行时阻止浏览器自动滚动。
- `auxclick` 在 `button === 1` 且命中标签行时阻止默认行为，并复用现有关闭动作。
- 标签行任意位置均可触发，包括固定标签、分组标签和关闭按钮区域。
- 分组标题、列表空白和新增标签按钮不响应中键关闭。
- 同一事件不得同时触发标签激活。

## 底部搜索框与图标

用户提供的 `搜索.svg` 和 `设置.svg` 分别保存为 `assets/icons/search.svg` 与 `assets/icons/settings.svg`。复制到扩展本地资源目录前必须清理 XML 声明、DOCTYPE、生成器时间、`p-id`、固定宽高和未使用的 `xlink` 命名空间，仅保留 `svg`、`viewBox` 和路径数据。资源不得包含脚本、事件属性、外部引用或内嵌远程内容。

底部工具栏改为单列全宽搜索容器：

- 搜索容器占满底部可用宽度。
- 搜索输入框占满容器，并保留现有 32px 高度和圆角。
- 左侧内嵌 `搜索.svg`，视觉尺寸为 16px，仅作装饰，设置 `aria-hidden="true"`。
- 右侧内嵌设置按钮，使用 `设置.svg`，视觉尺寸为 18px，点击区域保持 32px × 32px。
- 设置按钮保持“设置”的 `title` 和 `aria-label`，并保留键盘焦点样式。
- 输入框通过左右内边距避让图标，搜索文字不得与图标或按钮重叠。

两个 SVG 使用 CSS `mask` 渲染并继承 `currentColor`，确保浅色与深色主题下可见。HTML 不内联整段 SVG 路径，避免增加标记复杂度。

Chrome 原生 `input[type="search"]` 清除按钮隐藏，防止与右侧设置按钮重叠。现有 Escape 键清空输入或关闭历史结果的行为保持不变，不新增自定义清除按钮。

历史结果框继续向上展开，但左右边界改为与完整搜索容器一致，不再为外置设置按钮预留 42px。240px 和 180px 侧边栏宽度下，搜索容器、输入框和设置按钮不得产生横向滚动或遮挡。

## 事件同步与性能

侧边栏启动时先订阅 `tabs` 与 `tabGroups` 事件并开启缓冲，再并行读取当前窗口的标签和分组快照。快照完成后按接收顺序应用缓冲事件，最后执行一次联合渲染，避免启动窗口漏事件。

监听分组事件：

- `tabGroups.onCreated`
- `tabGroups.onUpdated`
- `tabGroups.onMoved`
- `tabGroups.onRemoved`

标签归属变化通过 `tabs.onUpdated` 的完整 `Tab` 对象更新 `groupId`。标签移动继续使用 `tabs.onMoved`。分组元数据变化只更新对应标题；分组折叠、移动、创建、删除或标签归属变化会重建联合列表。折叠标签不创建 DOM 节点。

不使用轮询，不在每个普通标签更新事件后全量查询。只有初始化、分组动作失败恢复和检测到不可调和的缺失状态时执行当前窗口快照重同步。

## 现有功能兼容

- “关闭下方标签页”按 Chrome 实际标签顺序计算，包括折叠分组中未渲染的标签；固定标签继续排除。
- favicon、激活、关闭、复制、设为快捷网站和历史搜索保持原行为。
- 固定操作导致分组归属变化时以 Chrome 事件结果为准。
- 右键菜单打开期间发生分组或标签删除时安全关闭。
- 页面清理时注销标签、分组、中键、菜单、对话框和拖动监听器。

## 错误处理

分组查询失败不阻止基础标签列表启动：侧边栏显示未分组标签并在状态栏提示无法读取分组。标签查询失败仍按现有方式停止标签展示。

用户发起的创建、加入、移出、折叠和拖动失败均显示明确错误。失败恢复查询使用单次并发快照；恢复查询也失败时保留当前可用视图，不循环重试。
