# Chrome Web Store 发布检查清单

## 安装与基础界面

- [ ] 在 `chrome://extensions` 开启开发者模式并加载 `dist`。
- [ ] 扩展图标在 16、32、48、128 像素场景显示清晰。
- [ ] 点击工具栏图标可以打开 side panel。
- [ ] 快捷入口默认关闭，关闭时不占用空白区域。
- [ ] 开启快捷入口后，默认 OpenAI、Google、GitHub 入口可见且可打开。

## 标签页与快捷入口

- [ ] 标签页搜索、切换、关闭、固定状态显示正常。
- [ ] 快捷入口支持新增、编辑、删除、排序、重置并持久化。
- [ ] 分别验证 1、20、100 个标签页及创建、更新、移动、关闭事件。
- [ ] 搜索对标题和域名生效，清空后恢复完整列表。
- [ ] 无效网址、保存失败、打开失败等错误有明确反馈。

## 隐私、安全与权限

- [ ] DevTools Network 确认扩展页面没有主动网络请求。
- [ ] HTTP/HTTPS favicon 显示文字 fallback，不触发图片请求。
- [ ] 权限精确为 `sidePanel`、`tabs`、`storage`，无 host permission 和 content script。
- [ ] 商店隐私披露与实际本地存储行为一致。
- [ ] 权限理由分别说明：侧边栏展示、当前窗口标签管理、本地保存快捷入口设置。

## 兼容与视觉

- [ ] Chrome 114 或更高版本可以加载扩展。
- [ ] 浅色、深色系统主题下均可辨识。
- [ ] 在 240、300、340、360 像素侧边栏宽度下检查布局、对话框和长文本。

## 构建产物

- [ ] `npm run package` 完整通过。
- [ ] ZIP 根目录直接包含 `manifest.json`，不包含 `dist/` 顶层目录。
- [ ] ZIP 不包含源码、source map、测试、文档或 `node_modules`。
- [ ] 在全新目录解压 ZIP 后重新执行一次“加载已解压”检查。
