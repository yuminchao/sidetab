## 0.10.0 发布验收

- [ ] 上传文件名为 `sidetab-lite-0.10.0.zip`，版本号与 `manifest.json`、`package.json`、`package-lock.json` 一致。
- [ ] 搜索收藏夹和历史记录时，每条结果显示清晰的来源标签，空查询不查询收藏夹。

- [ ] 扩展图标在 16、32、48、128 像素场景显示清晰。

- [ ] 新安装和缺少 `enabled` 旧设置的快捷入口默认开启，默认 OpenAI、Google、GitHub 入口可见且可打开。

## 标签页与快捷入口

- [ ] 标签页切换、关闭、固定状态显示正常。
- [ ] 加号按钮位于最后一个标签之后，并随标签列表滚动。
- [ ] 点击加号只创建并激活一个新标签页，请求期间无法重复点击。
- [ ] 空标签列表时加号仍可见、可点击。
- [ ] 标签页右键菜单支持复制、根据当前状态显示“固定标签”或“取消固定”、设为快捷网站、添加到分组、从分组中移除、关闭下方标签页和“打开最近关闭标签页”；“添加到分组”二级菜单支持选择已有分组或“新建分组”，鼠标悬停、键盘焦点和按下状态清晰，`Shift+F10`、方向键和 `Esc` 操作正常。
- [ ] 分组标题可展开或折叠，状态与 Chrome 原生标签组同步。
- [ ] 标签组标题行高度为 20px、标题字号为 14px，整行显示当前标签组颜色，浅色和深色主题下文字对比度足够。
- [ ] 标签组右键菜单支持在组内新建标签页、重命名分组、修改颜色和解散分组；执行期间禁用重复操作，失败后恢复可操作状态并同步 Chrome 真实状态。
- [ ] 鼠标中键点击标签页只关闭目标标签页，普通左键和非标签区域不会误触发。
- [ ] “关闭下方标签页”在当前标签之后存在普通标签时可用，无目标时禁用；执行后保留当前标签和所有固定标签，并通过单次批量关闭完成操作；批量关闭失败时显示明确提示。
- [ ] “打开最近关闭标签页”只恢复最近关闭的单个标签；没有标签记录时禁用，恢复失败时显示明确提示，恢复成功后菜单状态及时刷新。
- [ ] “关闭其他同类网站标签页”按完整 hostname 匹配并单次批量关闭，保留当前标签和固定标签；“快速分组同类网站”只处理同一窗口内未固定、未分组的至少两个候选标签。
- [ ] “设为快捷网站”保存当前 HTTP/HTTPS 页面的完整地址，名称优先使用标签标题；重复、超过 12 项、非法地址和保存失败均有明确反馈。
- [ ] 同组拖动和跨固定区拖动会同步 Chrome 顶部标签的真实顺序；跨组时固定状态正确变化。
- [ ] 快捷入口支持新增、编辑、删除、排序、重置并持久化。
- [ ] 快捷入口最多 12 项；添加第 13 项时操作被阻止并显示错误。
- [ ] “标签标题字号”可设置为 12 至 18 像素，默认值为 16 像素；分别在 12、18 像素边界检查标题无裁切、行高不变且列表无横向溢出。
- [ ] 设置中的“侧边栏位置”提示可打开 `chrome://settings/appearance`，连续点击只创建一个标签页，失败反馈明确。
- [ ] 分别验证 1、50、500 个标签页及创建、更新、移动、关闭事件。
- [ ] 底部搜索框不再过滤标签列表；聚焦或点击时的空查询最多读取 500 条历史候选，按主机名及端口与规范化路径去重后向上展示最近 20 条历史记录，确认没有调用收藏夹 API。
- [ ] 输入非空内容后才按需并行调用 `chrome.bookmarks.search()` 和历史搜索；最多 5 条收藏夹结果置顶，历史记录补足到总数最多 20 条，加载中、无结果、单侧失败降级和双侧失败反馈明确。
- [ ] 收藏夹与历史记录按同一规范化 URL 规则去重，跨来源重复时收藏夹优先。
- [ ] 历史结果隐藏 URL，只显示 favicon 和单行标题；点击或按 `Enter` 在新的活动标签页打开。
- [ ] 历史结果支持方向键循环选择，`Esc`、`Tab`、搜索框失去焦点、点击外部或打开设置时关闭；点击结果时仍可正常打开，快速输入不会显示过期结果。
- [ ] 无效网址、保存失败、打开失败等错误有明确反馈。

## 隐私、安全与权限

- [ ] 标签页图标优先使用 Chrome 提供的 `favIconUrl`。
- [ ] 快捷入口优先使用当前窗口内同源标签页的 `favIconUrl`；没有可用图标时尝试已缓存地址和站点的 `origin/favicon.ico`，加载失败后显示本地网络兜底图标，兜底图标不进入缓存。
- [ ] 历史记录图标优先使用当前窗口内同源标签页的 `favIconUrl`；没有可用图标时尝试站点的 `origin/favicon.ico`，加载失败后显示本地网络兜底图标。
- [ ] DevTools Network 记录符合披露：浏览器可能读取缓存，也可能请求 HTTP/HTTPS `favIconUrl`；必要时还可能请求 HTTP/HTTPS 站点的 `origin/favicon.ico`。
- [ ] 确认扩展没有使用 `fetch`、`XMLHttpRequest` 或第三方 favicon 服务，没有脚本网络连接，也没有远程代码。
- [ ] 确认收藏夹搜索只处理本次非空查询返回的有限结果：不遍历收藏夹树、不缓存完整收藏夹树、不注册收藏夹监听器，结果不持久化、不上传。
- [ ] 确认历史记录和收藏夹属于 Chrome 浏览器数据，扩展升级不会迁移或清除这些数据，升级后仍可按用户操作查询。
- [ ] 权限精确为 `sidePanel`、`tabs`、`tabGroups`、`storage`、`history`、`sessions`、`bookmarks`，没有 host permission 和 content script。
- [ ] CSP 精确为 `script-src 'self'; object-src 'self'; connect-src 'none'; img-src 'self' data: http: https:; style-src 'self'; frame-src 'none'`。
- [ ] 商店隐私声明明确说明：扩展不收集、不出售或向开发者服务传输用户数据；历史与收藏夹记录仅在本地按用户操作查询，不持久化搜索结果；最近关闭功能只在内存中缓存一个 `sessionId`，不持久化会话记录；浏览器加载 favicon 时可能直接向对应站点发送图片请求。
- [ ] 权限理由分别说明：侧边栏展示、当前窗口标签与原生标签组管理、本地保存快捷入口和字号设置、本地搜索 Chrome 历史记录、按需搜索 Chrome 收藏夹，以及读取并恢复最近关闭的单个标签。
- [ ] `bookmarks` 是必需权限；验证已有安装升级时 Chrome 可能要求接受新增权限，并在需要时提示用户到扩展管理页重新启用扩展。
