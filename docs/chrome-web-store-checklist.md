# Chrome Web Store 发布检查清单

## 安装与基础界面

- [ ] 在 `chrome://extensions` 开启开发者模式并加载 `dist`。
- [ ] 扩展图标在 16、32、48、128 像素场景显示清晰。
- [ ] 点击工具栏图标可以打开侧边栏。
- [ ] 快捷入口默认关闭，关闭时不占用空白区域。
- [ ] 开启快捷入口后，默认 OpenAI、Google、GitHub 入口可见且可打开。

## 标签页与快捷入口

- [ ] 标签页切换、关闭、固定状态显示正常。
- [ ] 加号按钮位于最后一个标签之后，并随标签列表滚动。
- [ ] 点击加号只创建并激活一个新标签页，请求期间无法重复点击。
- [ ] 空标签列表时加号仍可见、可点击。
- [ ] 标签页右键菜单支持复制、根据当前状态显示“固定标签”或“取消固定”、设为快捷网站、添加到分组、从分组中移除和关闭下方标签页；“添加到分组”二级菜单支持选择已有分组或“新建分组”，鼠标悬停、键盘焦点和按下状态清晰，`Shift+F10`、方向键和 `Esc` 操作正常。
- [ ] 分组标题可展开或折叠，状态与 Chrome 原生标签组同步。
- [ ] 鼠标中键点击标签页只关闭目标标签页，普通左键和非标签区域不会误触发。
- [ ] “关闭下方标签页”在当前标签之后存在普通标签时可用，无目标时禁用；执行后保留当前标签和所有固定标签，并通过单次批量关闭完成操作；批量关闭失败时显示明确提示。
- [ ] “设为快捷网站”保存当前 HTTP/HTTPS 页面的完整地址，名称优先使用标签标题；重复、超过 12 项、非法地址和保存失败均有明确反馈。
- [ ] 同组拖动和跨固定区拖动会同步 Chrome 顶部标签的真实顺序；跨组时固定状态正确变化。
- [ ] 快捷入口支持新增、编辑、删除、排序、重置并持久化。
- [ ] 快捷入口最多 12 项；添加第 13 项时操作被阻止并显示错误。
- [ ] “标签标题字号”可设置为 12 至 18 像素，默认值为 14 像素；分别在 12、18 像素边界检查标题无裁切、行高不变且列表无横向溢出。
- [ ] 设置中的“侧边栏位置”提示可打开 `chrome://settings/appearance`，连续点击只创建一个标签页，失败反馈明确。
- [ ] 分别验证 1、50、500 个标签页及创建、更新、移动、关闭事件。
- [ ] 底部搜索框不再过滤标签列表；聚焦或点击时向上展示最近 20 条历史记录。
- [ ] 输入内容后搜索 Chrome 本地历史记录并最多显示 20 条；加载中、无结果和失败状态反馈明确。
- [ ] 历史结果隐藏 URL，只显示 favicon 和单行标题；点击或按 `Enter` 在新的活动标签页打开。
- [ ] 历史结果支持方向键循环选择，`Esc`、`Tab`、点击外部或打开设置时关闭；快速输入不会显示过期结果。
- [ ] 无效网址、保存失败、打开失败等错误有明确反馈。

## 隐私、安全与权限

- [ ] 标签页图标优先使用 Chrome 提供的 `favIconUrl`。
- [ ] 快捷入口优先使用当前窗口内同源标签页的 `favIconUrl`；没有可用图标时尝试站点的 `origin/favicon.ico`，加载失败后显示名称首字符。
- [ ] 历史记录图标优先使用当前窗口内同源标签页的 `favIconUrl`；没有可用图标时尝试站点的 `origin/favicon.ico`，加载失败后显示名称首字符。
- [ ] DevTools Network 记录符合披露：浏览器可能读取缓存，也可能请求 HTTP/HTTPS `favIconUrl`；必要时还可能请求 HTTP/HTTPS 站点的 `origin/favicon.ico`。
- [ ] 确认扩展没有使用 `fetch`、`XMLHttpRequest` 或第三方 favicon 服务，没有脚本网络连接，也没有远程代码。
- [ ] 权限精确为 `sidePanel`、`tabs`、`tabGroups`、`storage`、`history`，没有 host permission 和 content script。
- [ ] CSP 精确为 `script-src 'self'; object-src 'self'; connect-src 'none'; img-src 'self' data: http: https:; style-src 'self'; frame-src 'none'`。
- [ ] 商店隐私声明明确说明：扩展不收集、不出售或向开发者服务传输用户数据；历史记录仅在本地按用户操作查询，不持久化搜索结果；浏览器加载 favicon 时可能直接向对应站点发送图片请求。
- [ ] 权限理由分别说明：侧边栏展示、当前窗口标签与原生标签组管理、本地保存快捷入口和字号设置，以及本地搜索 Chrome 历史记录。

## 兼容与视觉

- [ ] Chrome 114 或更高版本可以加载扩展。
- [ ] 浅色、深色系统主题下均可辨识。
- [ ] 在 180、240、300、360 像素侧边栏宽度下检查列表、设置对话框和长文本，页面不得出现横向滚动条。
- [ ] 固定标签与普通标签的站点图标和标题左侧对齐；普通标签保留不可见的固定图标占位，固定标签不显示“固定”文字。
- [ ] 搜索框和设置按钮始终固定在整个侧边栏最下方，不随标签列表滚动或内容数量变化而移位。
- [ ] 底部设置入口只显示齿轮，无普通按钮边框或背景，键盘焦点轮廓清晰。
- [ ] 搜索框为圆角样式且其上方没有分割线；历史结果框在底部工具栏上方向上展开，不遮挡搜索框和设置按钮。
- [ ] 快捷入口开启时，其与标签列表之间显示 1px 通栏分割线；关闭时分割线不占空间。
- [ ] 标签右键菜单使用微软雅黑字体栈，180px 宽度下主菜单和“添加到分组”二级菜单均不溢出；浅色、深色主题下拖动插入线均清晰可辨。
- [ ] 标签列表末尾的加号按钮为 44x24 像素紧凑带边框样式，所在行总高为 30 像素，且不会撑开列表布局。
