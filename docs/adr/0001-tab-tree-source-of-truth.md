# 标签树以 Chrome 打开来源为事实基础

标签树以 Chrome `openerTabId` 和扩展明确通过新增标签按钮设置的打开来源为父子关系基础，不把所有新标签推测为活动标签的子标签。用户在侧边栏中拖出子标签时，以浏览器会话级覆盖解除关系；该选择避免长期维护一套脱离 Chrome 的标签关系，同时允许用户显式修正树结构。

## 后果

- 父标签消失、关系无效、自引用或形成循环时，相关标签降级为根标签。
- 父子关系不跨越固定区域或 Chrome 原生标签组边界；边界恢复一致时可重新显示原关系。
- 会话覆盖只在当前浏览器会话有效，浏览器完全退出后根据仍有效的 Chrome 关系重新构建。
- 快捷网站、收藏夹、历史记录和复制标签默认不建立父子关系；侧边栏新增标签按钮在树模式下以活动标签为父标签。
