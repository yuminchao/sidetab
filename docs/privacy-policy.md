# SideTab Lite 隐私政策

生效日期：2026 年 8 月 20 日

SideTab Lite 是一个在 Chrome 侧边栏中管理当前窗口标签页的浏览器扩展。本政策说明扩展使用的数据、权限及网络行为。

## 数据处理

SideTab Lite 不收集、不出售、不共享用户数据，也不向开发者或第三方服务器上传用户数据。扩展没有开发者后端服务，不包含分析、广告或遥测代码。

扩展会在本地处理以下数据：

- 当前窗口的标签页标题、地址、固定状态、顺序和 Chrome 提供的 `favIconUrl`，用于显示和管理标签页。
- 用户配置的快捷网站、快捷入口开关、标签标题字号、内容树状态，以及网页悬浮球的启用状态和视口比例位置，使用 `chrome.storage.local` 保存在本机 Chrome 配置中。
- 用户主动打开、聚焦或输入侧边栏底部搜索框或网页悬浮球搜索框时查询到的 Chrome 收藏夹和历史记录。空查询只读取历史记录，按主机名及端口与规范化路径去重后显示最近 20 条，不读取收藏夹；输入非空内容后才按需并行调用 `chrome.bookmarks.search()` 和历史搜索，最多 5 条收藏夹结果置顶，历史记录补足到总数最多 20 条。跨来源按相同规范化 URL 去重，重复时收藏夹优先。
- 收藏夹查询只处理本次搜索返回的有限结果，不遍历收藏夹树、不缓存完整收藏夹树、不注册收藏夹监听器。收藏夹与历史搜索结果只保存在当前侧边栏页面内存中，不持久化、不上传，关闭或刷新侧边栏后即被清除；搜索框失去焦点后结果框会收起。
- 历史记录和收藏夹属于 Chrome 浏览器数据。扩展升级不会迁移或清除这些数据，升级后仍由 Chrome 保存并按用户操作提供查询结果。
- Chrome 最近关闭的标签记录。扩展只在当前侧边栏页面内存中缓存一个最近关闭标签的 `sessionId`，仅在用户选择“打开最近关闭标签页”时用于恢复该标签；不会保存完整会话列表，也不会持久化该标识。
- 用户主动开启网页悬浮球后，扩展会在 HTTP/HTTPS 普通网页中创建隔离的悬浮界面。悬浮球只处理自身的点击、拖拽、搜索和快捷操作，不读取或收集网页正文、表单内容、密码及其他页面业务数据。

## 权限用途

- `sidePanel`：在 Chrome 侧边栏中提供扩展界面。
- `tabs`：读取和管理当前窗口标签页，包括切换、创建、关闭、固定、复制和调整顺序。
- `tabGroups`：读取和管理当前窗口的 Chrome 原生标签组。
- `storage`：在本机保存快捷网站设置、快捷入口开关、标签标题字号、内容树状态、悬浮球开关和悬浮球位置。
- `history`：仅在用户操作搜索框时，本地查询 Chrome 历史记录并展示匹配结果。
- `sessions`：读取并恢复 Chrome 最近关闭的单个标签页。
- `bookmarks`：仅在搜索框中存在非空查询时，按需读取 Chrome 本地收藏夹中的匹配结果。
- `scripting`：仅在用户主动开启网页悬浮球时，将扩展包内置的本地内容脚本注入已经打开的 HTTP/HTTPS 标签页，使悬浮球无需刷新网页即可立即显示。该权限不用于执行远程代码或采集网页内容。
- HTTP/HTTPS 主机权限（`http://*/*`、`https://*/*`）：仅用于在普通网页中显示用户可选的悬浮球，并支持悬浮球提供的标签搜索、标签操作、打开侧边栏和一键分组功能。悬浮球默认关闭，不在 `chrome://`、扩展页、新标签页等受限页面运行。

扩展申请的主机权限和内容脚本仅服务于上述悬浮球功能。扩展不读取、收集、保存或上传网页正文、表单内容、密码及用户在网页中的输入，不执行远程代码，也不将浏览数据发送到开发者服务器。

## 网络与网站图标

扩展不使用 `fetch`、`XMLHttpRequest` 或第三方 favicon 服务，不通过脚本建立网络连接，也不加载远程代码。扩展页面 CSP 禁止脚本网络连接和嵌入远程页面。

为了显示网站图标，页面中的图片元素可能加载 Chrome 提供的 HTTP/HTTPS `favIconUrl`，或在缺少图标时尝试网站的 `origin/favicon.ico`。浏览器可能使用缓存，也可能直接向对应网站发出图片请求；该请求可能向网站暴露常规网络信息，例如 IP 地址和请求头。扩展不会将这些图标请求转发到开发者服务。

## 数据保留与控制

历史与收藏夹搜索结果和最近关闭标签的 `sessionId` 不会被持久化。用户可以在设置中关闭网页悬浮球、修改或重置快捷网站，也可以通过 Chrome 的扩展管理页面移除 SideTab Lite；移除扩展时，Chrome 会处理其本地存储数据。

`bookmarks` 是收藏夹搜索所需的权限；HTTP/HTTPS 主机权限和 `scripting` 是网页悬浮球所需的权限。已有安装升级到包含这些权限的版本时，Chrome 可能要求用户接受新增权限；在用户确认前，可能需要在扩展管理页重新启用扩展。悬浮球功能默认关闭，用户可随时在侧边栏设置中开启或关闭。

## 政策更新

如果扩展的数据处理方式发生实质变化，本政策会随新版本更新生效日期和说明。
