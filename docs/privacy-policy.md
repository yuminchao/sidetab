# SideTab Lite 隐私政策

生效日期：2026 年 7 月 31 日

SideTab Lite 是一个在 Chrome 侧边栏中管理当前窗口标签页的浏览器扩展。本政策说明扩展使用的数据、权限及网络行为。

## 数据处理

SideTab Lite 不收集、不出售、不共享用户数据，也不向开发者或第三方服务器上传用户数据。扩展没有开发者后端服务，不包含分析、广告或遥测代码。

扩展会在本地处理以下数据：

- 当前窗口的标签页标题、地址、固定状态、顺序和 Chrome 提供的 `favIconUrl`，用于显示和管理标签页。
- 用户配置的快捷网站、快捷入口开关和标签标题字号，使用 `chrome.storage.local` 保存在本机 Chrome 配置中。
- 用户主动聚焦或输入底部搜索框时查询到的 Chrome 历史记录。扩展最多读取 500 条候选记录，按主机名及端口与规范化路径去重后展示最多 20 条。历史查询结果仅保存在当前侧边栏页面内存中，不会持久化，关闭或刷新侧边栏后即被清除；搜索框失去焦点后结果框会收起。
- Chrome 最近关闭的标签记录。扩展只在当前侧边栏页面内存中缓存一个最近关闭标签的 `sessionId`，仅在用户选择“打开最近关闭标签页”时用于恢复该标签；不会保存完整会话列表，也不会持久化该标识。

## 权限用途

- `sidePanel`：在 Chrome 侧边栏中提供扩展界面。
- `tabs`：读取和管理当前窗口标签页，包括切换、创建、关闭、固定、复制和调整顺序。
- `tabGroups`：读取和管理当前窗口的 Chrome 原生标签组。
- `storage`：在本机保存快捷网站设置、快捷入口开关和标签标题字号。
- `history`：仅在用户操作搜索框时，本地查询 Chrome 历史记录并展示匹配结果。
- `sessions`：读取并恢复 Chrome 最近关闭的单个标签页。

扩展不申请主机权限，不注入 content script，也不读取网页正文、表单或密码。

## 网络与网站图标

扩展不使用 `fetch`、`XMLHttpRequest` 或第三方 favicon 服务，不通过脚本建立网络连接，也不加载远程代码。扩展页面 CSP 禁止脚本网络连接和嵌入远程页面。

为了显示网站图标，页面中的图片元素可能加载 Chrome 提供的 HTTP/HTTPS `favIconUrl`，或在缺少图标时尝试网站的 `origin/favicon.ico`。浏览器可能使用缓存，也可能直接向对应网站发出图片请求；该请求可能向网站暴露常规网络信息，例如 IP 地址和请求头。扩展不会将这些图标请求转发到开发者服务。

## 数据保留与控制

历史搜索结果和最近关闭标签的 `sessionId` 不会被持久化。用户可以在设置中修改或重置快捷网站，也可以通过 Chrome 的扩展管理页面移除 SideTab Lite；移除扩展时，Chrome 会处理其本地存储数据。

## 政策更新

如果扩展的数据处理方式发生实质变化，本政策会随新版本更新生效日期和说明。
