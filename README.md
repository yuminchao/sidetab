# SideTab Lite

SideTab Lite 是一个 Chrome 侧边栏标签页管理扩展。它支持切换、关闭、固定、分组和拖动排序当前窗口的标签页，也可通过鼠标中键快速关闭标签页；同时提供收藏夹与历史记录搜索及可配置的快捷网站入口。快捷入口默认开启，默认包含 OpenAI、Google、GitHub，设置保存在 Chrome 本地存储中。旧设置缺少 `enabled` 字段时会迁移为开启；用户显式关闭后仍保持关闭，恢复默认时重新开启并恢复三个默认网站。

## 安装到 Chrome

1. 运行 `npm install` 和 `npm run package`，生成 `dist/`。
2. 打开 `chrome://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目的 `dist` 目录。
5. 点击工具栏中的 SideTab Lite 图标打开侧边栏。

也可以按 `Alt+V` 打开扩展侧边栏；若快捷键被其他扩展占用，可在 `chrome://extensions/shortcuts` 中重新分配。

`release/sidetab-lite-0.12.4.zip` 用于上传 Chrome Web Store 或传递构建产物。Chrome 通常不能直接双击 ZIP 安装扩展；本地测试请加载已解压的 `dist` 目录。

0.12.4 发布重点：设置中的“内容树”默认关闭并兼容旧配置迁移；“同网站快速分组”会优先复用实际包含同类成员的分组，新“一键分组”可批量整理普通网站、本地文件和 Chrome 内部页面。

## 开发与打包

需要 Node.js 20.11 或更高版本。项目锁定 Vite 6.4.3，请使用仓库中的 `package-lock.json` 安装一致的依赖版本。

```powershell
npm install
npm test -- --run
npm run package
```

`npm run package` 会依次执行类型检查、测试、构建和发布检查，再按固定文件顺序与时间戳生成并自验 ZIP。重复打包会覆盖目标 ZIP，但不会删除 `release/` 中的其他文件。`npm run generate:icons` 可重新生成仓库中的图标资源；发布产物精确包含 15 个审核文件，其中图标资源为四个扩展 PNG 图标和五个 SVG（定位、固定、网络兜底、搜索、设置），不包含新增标签页 SVG，也不包含兼容保留的快捷网站 PNG。

## 使用说明

设置中的“标签标题字号”范围为 12 至 18 像素，默认值为 14 像素；已经保存的有效字号保持不变。快捷入口最多可配置 12 项；快捷入口默认开启，用户显式关闭后会隐藏，点击恢复默认会重新开启并恢复 OpenAI、Google、GitHub。标签列表末尾使用 44x24 像素、有边框且水平垂直居中的文本 `+` 按钮新增标签页。
快捷网站栏最右侧固定显示“定位当前标签”按钮；点击后会先展开隐藏当前标签的折叠路径，再将当前活动标签滚动到列表中部并把键盘焦点移到该标签，不触发 Chrome 标签切换。关闭快捷入口时，该按钮随快捷网站栏一同隐藏。

“内容树”默认关闭。开启后，标签树使用箭头表示父节点、使用圆点表示非根级叶子节点，新标签自动成为当前活动标签的子节点；旧设置中的 `child` 会迁移为开启，`root` 会迁移为关闭。拖动标签时，标签上方和下方的定位线表示移动为目标同级，中间整行高亮表示创建为目标的直接子节点；横向移动不改变层级，定位线缩进只反映目标现有深度。下方定位线和直接子节点投放都以目标完整子树末端为排序边界，拖动父节点时内部子树结构保持不变，最多支持四级嵌套。包含当前活动标签的树允许手动折叠，折叠祖先以强调色箭头提示；普通标签切换不会强制展开，只有整行高亮创建直接子节点成功或新建并激活子标签时自动展开对应路径。

分组标题最右侧显示当前分组包含的标签页数量，折叠分组后数量仍然可见。设置对话框提供 Chrome 外观设置入口，用于调整整个 Chrome 侧边栏位于左侧或右侧；扩展不读取或保存该位置。底部设置入口仅显示齿轮图标，标签右键菜单优先使用微软雅黑。

底部搜索框用于搜索 Chrome 本地收藏夹和历史记录，不会过滤当前标签页。聚焦搜索框时的空查询只读取最近 500 条历史候选，按主机名及端口与规范化路径去重后显示最近 20 条，不查询收藏夹。输入非空内容后，扩展才按需并行调用 `chrome.bookmarks.search()` 和 Chrome 历史搜索；最多 5 条收藏夹结果置顶，历史记录补足到总数最多 20 条。跨来源仍按同一规范化 URL 规则去重，重复时收藏夹优先。结果框向上展开，搜索框失去焦点后自动收起；选择结果会在新的活动标签页中打开。

每次非空搜索只处理本次 Chrome API 返回的有限结果。扩展不遍历收藏夹树、不缓存完整收藏夹树、不注册收藏夹监听器；收藏夹搜索结果只保存在当前侧边栏内存中，不持久化、不上传。

历史记录和收藏夹属于 Chrome 浏览器数据。扩展升级不会迁移或清除这些数据，升级后继续按用户操作从 Chrome 查询；扩展自身也不会复制或持久化搜索结果。

标签页右键菜单支持复制、固定或取消固定、设为快捷网站、添加到分组、从分组中移除、同网站快速分组、一键分组、关闭下方标签页、关闭其他同类网站标签页和打开最近关闭标签页。“添加到分组”的二级菜单可选择已有分组或“新建分组”。“同网站快速分组”按标签的实际分类复用已经包含同类成员的分组，也可为单个标签以及本地文件、Chrome 设置和其他 Chrome 页面创建分组。“一键分组”只处理未固定且未分组的候选：同一普通网站的多个标签各自按网站分组，普通网站单例进入会话级“其他”角色分组，本地文件、Chrome 设置和其他 Chrome 页面分别成组；固定标签不参加。智能分组遇到部分失败时保留 Chrome 已完成的结果，停止后续操作并重新同步真实状态；该功能不新增权限、轮询或长期缓存。关闭其他同类网站标签页会保留当前标签和所有固定标签。分组标题可展开或折叠，折叠状态会同步到 Chrome。鼠标中键点击标签页会直接关闭该标签页。“关闭下方标签页”只关闭当前标签之后的普通标签，保留当前标签和所有固定标签。“打开最近关闭标签页”恢复 Chrome 最近关闭的单个标签；没有可恢复记录时该菜单项不可用。新快捷网站保存页面完整地址，名称优先使用标签标题。

标签组标题行采用 20px 紧凑高度和固定 14px 字号，整行使用 Chrome 标签组颜色。标签组右键菜单支持在组内新建标签页、重命名分组、修改颜色和解散分组；批量操作在执行瞬间根据最新标签状态重算目标，失败时重新同步 Chrome 真实状态，不预改界面数据。

标签页图标优先使用 Chrome 为该标签页提供的 `favIconUrl`。快捷入口优先使用当前窗口内同源标签页的 `favIconUrl`；没有可用图标时，再尝试对应 HTTP/HTTPS 站点的 `origin/favicon.ico`，失败后显示本地网络兜底图标，且兜底图标不进入缓存。

## 隐私与权限

扩展只申请 `sidePanel`、`tabs`、`tabGroups`、`storage`、`history`、`sessions` 和 `bookmarks` 权限，不申请主机权限，也不注入 content script。`tabGroups` 仅用于读取和管理当前窗口的 Chrome 原生标签组；`history` 仅用于用户操作底部搜索框时，在本地查询并展示 Chrome 历史记录；`sessions` 仅用于读取并恢复最近关闭的单个标签；`bookmarks` 仅用于非空搜索时读取匹配的本地收藏夹结果。扩展只缓存一个 `sessionId`，不会持久化会话记录。历史与收藏夹查询结果也不持久化或上传。扩展不收集、不出售，也不向开发者服务传输用户数据。

`bookmarks` 是收藏夹搜索所需的必需权限。已有安装升级到包含该权限的版本时，Chrome 可能要求用户接受新增权限；在用户确认前，可能需要在扩展管理页重新启用扩展。

图标只通过页面中的图片元素显示。浏览器可能使用已有缓存，也可能为 Chrome 提供的 HTTP/HTTPS `favIconUrl` 发出图片请求；必要时，浏览器还可能请求 HTTP/HTTPS 站点的 `origin/favicon.ico`。这些请求会直接到达相应站点，并可能向站点暴露常规请求信息。

扩展不使用 `fetch`、`XMLHttpRequest` 或第三方 favicon 服务，不通过脚本建立网络连接，也不加载远程代码。扩展页面 CSP 保持 `connect-src 'none'` 和 `frame-src 'none'`，脚本与样式只允许扩展自身；仅图片来源允许扩展自身、`data:`、`http:` 和 `https:`。用户点击快捷入口后，Chrome 才会打开对应网站。

完整说明见 [隐私政策](docs/privacy-policy.md)。
